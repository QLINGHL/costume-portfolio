# 015 异环式都市时装 · 都市夜行者风衣套装

整套服装：异环式都市时装——藏青修身风衣 + 黑色高领内搭 + 橙色围巾 + 猫耳 + 蓝色挑染。
015 号作品，按 001 v2 确立的组件化流程（L1 → L2 → L3）从零制作。
BACKLOG 最上面未勾项；BACKLOG 本轮已空，按 README 四方向自选：**异环都市时装线首件整套**（DESIGN.md 有这条线，此前未做过整套）。

## 角色故事

她白天在便利店打工，夜里穿风衣出任务——处理这座城市里不该被
看见的东西。橙色围巾是她接单的信号：围巾一系上，今晚就有人要
付钱。猫耳不是装饰，是异环的标记；头发里那一绺蓝，是她唯一
不肯剪掉的、属于她自己的颜色。风衣要修身：都市行动讲究跑得动，
拖摆和层叠都留在别的世界。

## 线路与融合变量

- 线路：异环式都市时装（DESIGN.md：现代都市日常服、职业一眼可辨、
  现实配色、版型合体修身、非人元素点缀）——先定职业再定剪裁：
  都市夜行处理员，风衣 + 高领 + 腰带 + 短靴，一眼能读出“夜里干活的人”。
- 融合变量只改一个：**配色走都市现实调**（藏青 + 黑 + 灰，橙色点缀），
  廓形保持都市修身风衣，不用原神式层叠拖摆与大面积高饱和；
  非人元素只做小面积点缀（猫耳 + 蓝挑染），不抢都市服的主调。

## 廓形

- **风衣 + 高领**：藏青风衣从肩到腰修身（0.295→0.292），腰下微张
  到及膝摆（0.340→0.410），下半身藏青、上半身藏青，靠黑内搭与
  橙围巾读出层次；黑色高领只在领口露一圈，是全套最克制的一笔。
- **围巾**：橙色颈环戴在立领外面（z 1.36–1.42，r 0.34），绳结压在
  环前正中，一条两段式短尾垂到上胸（相机侧右前，尾端 z=1.24，
  止于最上排扣上方，不挡双排扣；尾在 z=1.34 处向外折，越过立领外张）。
- **猫耳 + 蓝挑染**：猫耳根埋进黑发、尖出头顶 0.06 米，是全套
  唯一的非人标记；蓝挑染贴在黑发前右侧，扁椭圆竖绺，颜色一亮
  整张脸就有了焦点。
- **整体剪影**：修身风衣及膝只露靴筒，人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

## 沿用 001 v2 / 002 / 003 / 004 / 005 / 007 / 008 / 009 / 011 / 014 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；人偶最简五官：两只眼睛。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片/圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
- 挂件要放在看得见的位置（008 膝盘被裙摆挡住的教训：
  围巾尾放相机侧右前、袖标放相机侧左臂、口袋巾放左胸，不藏在层下；
  围巾尾端止于 z=1.30，不挡最上排扣）。
- 同色浮雕看不见（003 的教训）：褶裥用灰压在藏青风衣上、双排扣用灰
  压在藏青风衣上、口袋巾用橙压在藏青风衣上，靠色差读出层次。
- 底座不建赤脚（008 的教训）：裤管到地面 + 楔形脚掌，短靴盖住
  裤管与脚掌，脚不悬空。
- **013 质检的教训**：靴掌楔形中心 z=0.0 落地（011 的靴底悬空 0.02 米）；
  腰带下沿须比同高风衣宽（011 腰带下沿 6 个顶点落在罩裙锥面内）——
  本轮腰带上窄下张（0.345→0.360），下沿比同高风衣宽 0.037。
- 相机侧配饰才看得见（008 圆盾的教训）：袖标、口袋巾、围巾尾
  一律放相机侧（+x / -y 前侧）。
- **围巾返工（v1 → v2，本轮）**：v1 围巾环在 z 1.44–1.50、r 0.24，
  套在头球最宽处，正好横在眼鼻之间，读着像口罩；v2 把环降到
  z 1.36–1.42、r 0.34，戴在立领外面读成颈巾，绳结移到 (0, -0.345, 1.39)，
  尾改两段式（z=1.34 处向外折越过立领外张，尾端 z=1.24），
  最上排扣随之下移到 z=1.20，尾不挡扣。
- **蓝挑染返工（v1 → v2，本轮）**：v1 挑染纵向拉长 2.2（z 1.53–1.75），
  顶端戳出头顶读成蓝色莫霍克；v2 改拉长 1.5、中心降到 z=1.60，
  贴发面平放，只露 0.036 浮雕。
