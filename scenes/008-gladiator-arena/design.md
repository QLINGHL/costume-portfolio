# 008 角斗士竞技套装 · Gladiator Arena Set

鸣潮黎那汐塔风：角斗士铠甲 + 红披风 + 腿甲（奥古斯塔线）。
008 号作品，按 001 v2 确立的组件化流程（L1 → L2 → L3）从零制作。

## 角色故事

黎那汐塔竞技场的角斗士——衣服就是战绩，站上沙场不用开口。
古铜胸甲讲的是百战（铜是打出来的颜色，不是镀出来的），深红披风
讲的是血与喝彩（披风一扬就是入场），胸前的金桂冠是他的胜场
（看衣服就知道他赢过多少场），头顶的红羽冠是他的旗帜
（观众席最后一排也能认出他）。圆盾不背在身后，绑在右臂上——
角斗士的盾是进攻的一部分，不是行李；盾绑在右臂（相机侧），
3/4 正面一眼能看见。

## 线路与融合变量

- 线路：鸣潮式机能风的地区衣橱分支——黎那汐塔角斗士铠甲
  （DESIGN.md：嘉年华与角斗士铠甲同属黎那汐塔地区衣橱，
  007 已做嘉年华，008 做同地区的另一套衣橱）。
- 融合变量只改一个：廓形保持角斗士铠甲（胸甲 + 肩甲 + 裙甲 +
  腿甲 + 披风），不套机能风的绑带战术件、不套原神的层叠长袍；
  配色走竞技场高饱和（古铜 + 深红 + 象牙白 + 金），不用机能风的
  黑白打底。

## 廓形

- **上身**：古铜胸甲修身挺括，胸前金桂冠一眼读出“胜者”；象牙白
  内衬只在领口露一线，拉开明度。
- **肩臂**：古铜半球肩甲是全套最圆的廓形，与挺括的胸甲形成
  圆 / 直对比；右臂圆盾是第二视觉重心。
- **披风**：深红全披风盖后背、垂至膝后，从肩头随身体外张，金边
  压住下摆；正面完全敞开，不挡胸前的桂冠。
- **下身**：深红短裙腰至膝上，八道古铜裙甲片绕裙一周，金环收底；
  古铜腿甲接住裙摆，膝前金盘点睛。
- **首**：金桂冠环 + 深红羽冠是全套的最高点，羽冠前后向、
  高出头顶，是竞技场里最远的辨识点。
- **整体剪影**：上挺下张、羽冠拉高、披风拉宽，角斗士的“张扬”
  靠羽冠 + 披风 + 肩甲三处撑起来；人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

- 配色逻辑：古铜与深红都是饱和暖色，靠象牙白内衬在领口拉开明度，
  金色只占约 5%，是“胜场功能色”（桂冠、扣具、收边），不是装饰色。

  层间隙 ≥0.005 米保证阴影缝；轮廓光不能省。

## 面数目标（整套 ≤1200，目标约 900）

内衬短袍约 24、胸甲约 24、胸甲金边约 48、桂冠纹约 34、肩甲约 128、
臂铠约 96（含腕金环）、圆盾约 20、腰带约 24、裙甲约 36、裙甲片约 32、
裙摆金边约 24、腿甲约 96（含膝盘与顶环）、战凉鞋约 36、红披风约 60、
披风金边约 24、披风扣约 6、桂冠约 36、羽冠约 12。合计约 760。

实测（2026-11-21 21:10 轮次）：整套 **593 面**（三角 82 + 四边 511，
N-gon 0），L2 ALL PASS、L3 PASS，FRAME_FRACTION 0.700，目视通过。
低于估算主因是胸甲/短袍/裙甲用的椭圆筒环数少（每件仅 24–48 面），
肩甲球体环数少（每件仅 32 面），裙甲片每条仅 2 面。
返工（轮次内 v1 → v2）：腕部金环半径 0.092 → 0.096（L2 间隙不合格）；
膝前金盘 z=0.38 → z=0.28（首渲被裙摆挡住看不见）；圆盾左臂 → 右臂
（首渲只露一个边）；披风弧面 15°–165° → 10°–170°（首渲正面只有
肩头一线红）。

## 沿用 001 v2 / 002 / 003 / 004 / 005 / 007 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；底座不建赤脚，脚由战凉鞋提供。
- 人偶最简五官：两只眼睛，3/4 正面一眼认出正面。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片/圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
- 裙甲片必须用比底色亮一档的颜色（003 的教训，同色 0.004 浮雕看不见）。
- 袖管/臂铠起点要盖过肩点（005 的教训：开口朝上会透出人偶手臂顶盖）。
- 披风弧面 10°–170°（007 的教训：30°–150° 正面只剩一线红边；
  008 v1 的 15°–165° 在 3/4 正面仍只有肩头一线红，10°–170° 才让
  两侧红边带进画面，同时仍不遮正面）。
- 膝前金盘要放在裙摆下沿之下（008 v1 的教训：金盘放在 z=0.38 被
  裙摆完全挡住，正面根本看不见；移到 z=0.28 才露出）。
- 圆盾绑在相机侧手臂（008 v1 的教训：绑左臂时在 3/4 正面只露
  一个边，移到右臂才一眼认出是盾）。
- 羽冠底座要高于发顶（发顶 z=1.76），羽冠勿压眼睛。

## 返工记录（v1 → v2，轮次内）

- 腕部金环半径 0.092 → 0.096：L2 间隙 0.003 < 0.005 不合格，改后全过。
- 膝前金盘 z=0.38 → z=0.28：首渲金盘被裙摆完全挡住，正面看不见；
  移到裙摆下沿之下才露出。
- 圆盾左臂 → 右臂：首渲左臂盾在 3/4 正面只露一个边，移到相机侧
  （右臂）才一眼认出是盾。
- 披风弧面 15°–165° → 10°–170°：首渲披风在 3/4 正面只有肩头一线
  红，放宽后两侧红边带进画面，同时仍不遮正面。
