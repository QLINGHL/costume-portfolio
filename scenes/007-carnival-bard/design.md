# 007 嘉年华吟游诗人套装 · Carnival Bard Set

鸣潮黎那汐塔风：嘉年华配色 + 半斗篷 + 羽毛饰 + 诗人帽。
007 号作品，按 001 v2 确立的组件化流程（L1 → L2 → L3）从零制作。

## 角色故事

黎那汐塔嘉年华上的吟游诗人——衣服就是演出服，走到哪唱到哪。
深紫短上衣讲的是夜晚的嘉年华（紫是狂欢夜的主色），绯红斗篷讲的是
舞台（斗篷一扬就是开场），胸前的金色音符是他的乐谱（不用开口，
看衣服就知道他是唱歌的），诗人帽上的三根羽毛是他去过的三座城。
面具不戴在脸上，挂在腰间——嘉年华的面具是邀请，不是伪装。

## 线路与融合变量

- 线路：鸣潮式机能风的地区衣橱分支——黎那汐塔嘉年华（DESIGN.md：
  每个地区有自己的衣橱，嘉年华与角斗士铠甲同属黎那汐塔）。
- 融合变量只改一个：廓形保持嘉年华演出服（短上衣 + 半斗篷 +
  泡泡袖 + 短裙），不套机能风的绑带战术件、不套原神的层叠长袍；
  配色走嘉年华高饱和（深紫 + 绯红 + 象牙白 + 金），不用机能风的
  黑白打底。

## 廓形

- **上身**：深紫短上衣修身挺括，立领竖起、胸前三枚金扣 + 三枚金音符
  一眼读出“吟游诗人”；象牙白内衬只在领口露一线，拉开明度。
- **袖**：象牙白泡泡袖中部膨起、袖口金环收窄，是全套最圆的廓形，
  与挺括的上衣形成圆 / 直对比。
- **披风**：绯红半斗篷只盖后背，从肩头垂到腰下、随身体外张，金边
  压住下摆；正面完全敞开，不挡胸前的音符。
- **下身**：深紫短裙腰至膝上，八道绯红裙褶绕裙一周，金环收底；
  绯红长靴接住裙摆，靴身金线收边。
- **首**：宽檐诗人帽是全套的最高点，三根羽毛斜插帽侧（金 / 绯红 /
  象牙白各一），帽檐压住发顶但不遮眼睛。
- **整体剪影**：上挺下张、帽子拉高、斗篷拉宽，嘉年华的“张扬”
  靠帽 + 斗篷 + 泡泡袖三处膨起来；人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

- 配色逻辑：深紫与绯红都是饱和暗色，靠象牙白泡泡袖 + 内衬在中段
  拉开明度，金色只占约 5%，是“演出功能色”（音符、扣具、收边），
  不是装饰色。
- **深紫一团糊的防线**：短上衣哑光（粗糙度 0.85）、金色五金
  （0.35 + 金属度 0.7）提亮、象牙白袖子拉开明度对比；层间隙
  ≥0.005 米保证阴影缝；轮廓光不能省。

## 纹理（全部用几何体，不靠贴图——001 v2 的标准）

| 纹理 | 做法 |
|---|---|
| 音符纹×3 | 金色小盒拼成音符（符头方块 + 符干细条 + 符尾斜条），高出上衣面 0.007 米，几何呈现 |
| 金纽扣×3 | 金色小方扣，沿胸前中线，高出上衣面 0.008 米 |
| 裙褶 | 8 条竖向凸条绕裙一周，每条高出裙面 0.006 米、宽 0.032 米，\n  用绯红（#B02040）做褶裥，以色差读出立体感（003/004 的教训：\n  同色褶裥在渲染里看不见；深紫裙 + 绯红褶反差足够） |
| 斗篷金边 | 斗篷下摆一圈金色弧环，高出斗篷面 0.004 米 |
| 裙摆金边 | 裙摆底边一圈金色细环，高出裙面 0.004 米 |
| 羽毛×3 | 三根细羽（薄长盒，斜插帽侧），金 / 绯红 / 象牙白各一 |
| 面具挂件 | 金色半面圆盘 + 两点黑眼，系绳挂在腰封前 |
| 靴底金线 | 靴身前缘一条金色细条 |

## 面数目标（整套 ≤1200，目标约 800）

内衬约 48、短上衣约 48、立领约 24、金纽扣约 18、音符纹约 54、
泡泡袖约 80（含袖口金边）、半斗篷约 44（含金边与搭扣）、腰封约 18、
短裙约 36、裙褶约 24、裙摆金边约 12、长靴约 88、诗人帽约 84、
羽毛约 18、面具约 28。合计约 624。

实测（2026-11-21 17:10 轮次）：整套 **574 面**（三角 54 + 四边 520，
N-gon 0），L2 ALL PASS、L3 PASS，FRAME_FRACTION 0.745，目视通过。
低于估算主因是上衣/内衬/短裙用的椭圆筒环数少（每件仅 24–36 面），
音符/纽扣/羽毛用的小方盒每件仅 6 面。
返工（轮次内 v1 → v2）：首渲斗篷在 3/4 正面只露一线红边——斗篷弧面
从 30°–150° 放宽到 15°–165°（仍只盖后背，双肩处红边更明显），
重渲后 L2/L3 仍全过、面数不变。

## 返工记录（v1 → v2，轮次内）

  放宽弧面后双肩处红边可见；其余组件未动。

## 沿用 001 v2 / 002 / 003 / 004 / 005 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；底座不建赤脚，脚由长靴提供。
- 人偶最简五官：两只眼睛，3/4 正面一眼认出正面。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片/圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
- 褶裥必须用比底色亮一档的颜色（003 的教训，同色 0.004 浮雕看不见）。
- 袖管起点要盖过肩点（005 的教训：袖口开口朝上会透出人偶手臂顶盖）。
- 宽檐帽檐要高于发顶（发顶 z=1.76），帽檐勿压眼睛。
