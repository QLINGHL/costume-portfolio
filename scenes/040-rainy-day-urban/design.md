# 040 异环式都市时装 · 雨天套装

## 设计说明

- **灵感来源**：异环式都市时装第十件——雨天场景方向。学院 / 居家 / 运动 /
  街头 / 通勤 / 夜行 / 夏日 / 冬日 / 秋日矩阵里雨天首次做。雨天是都市日常
  的另一面：亮黄雨衣是雨天街头最显眼的颜色，雨伞是第六种手持物
  （015 围巾之后：026 书包、029 公文包、031 沙滩包、032 咖啡杯、
  036 罗盘、039 托叶，雨伞是第六种）。
- **廓形**：沿用 039 中长风衣，到大腿中部 z 0.60，前开襟露奶油白高领
  毛衣。变量是面料与配件：雨衣是光面 PVC（粗糙度 0.25，有别于布料
  0.6），脑后翻着雨衣兜帽；高筒雨靴到小腿中部 z 0.50，比 039 短靴高。
- **配色**（主色 3 个 + 1 个点缀色；sRGB hex → linear，写死，v1 洗淡
  的根因就是把 sRGB 值当 linear 用）：

  | 角色 | sRGB hex | linear RGB | 用途 |
  | --- | --- | --- | --- |
  | 雨衣黄 | #F2C200 | (0.888, 0.540, 0.000) | 雨衣、雨靴、雨帽、兜帽、伞面 |
  | 藏青 | #1B2A4A | (0.011, 0.023, 0.068) | 长袖、长裤、腰带、帽带、靴环下沿、手套 |
  | 奶油白 | #F5EFE0 | (0.913, 0.862, 0.744) | 高领毛衣、袖口 |
  | 雨滴蓝（点缀） | #5EB3E6 | (0.112, 0.452, 0.791) | 雨滴纹×6、蓝挑染 |
  | 银 | #C0C8D0 | (0.529, 0.585, 0.633)，metallic 0.7 | 腰扣、靴环、伞柄、伞尖 |
  | 金 | #C9A227 | (0.584, 0.361, 0.020)，metallic 0.6 | 耳钉 |
  | 肤色 / 黑发 / 眼 | — | (0.694, 0.381, 0.209) / (0.011, 0.011, 0.015) / (0.003, 0.003, 0.003) | 人偶底座 |

- **纹样**：雨滴纹×6，几何体呈现——扁椭球水滴（r 0.028，缩放
  (0.9, 0.55, 1.35)，高 0.076 米），半嵌衣面、凸起约 0.015 米。
  毛衣前胸 3 滴（270° z 1.32；262°/278° z 1.02），雨衣前襟边
  2 滴（225°/315° z 1.05，落在开襟楔边外 15°，不悬在开襟空处），
  雨帽正面 1 滴（0, -0.207, 1.70）。雨滴纹是全线首次的纹样做法
  （此前是星形贴片 / 云纹 / 雪花 / 波纹环）。
- **褶裥**：雨衣下摆立体褶裥片×8（026/030/032/036 同款闭合薄 solid，
  内沿离衣面 0.004、外沿 0.026），角度 170/200/230/320/350/20/50/110，
  全部在开襟楔（240°–300°）之外。
- **部件清单**：雨衣（前开襟 arc 300°–600°，5 环，z 1.50–0.60）、
  奶油白高领毛衣（5 环，z 1.50–0.62）、雨滴×6、褶裥×8、藏青腰带
  （z 0.94–0.88）+ 银腰扣、藏青长袖×2 + 奶油白袖口×2、藏青长裤、
  雨衣黄高筒雨靴×2 + 银靴环×2 + 靴底楔、雨衣黄宽檐雨帽（檐 r 0.34，
  031 遮阳帽做法）+ 藏青帽带、雨衣黄兜帽（背部弧面 15°–165°，
  z 1.52–1.38，翻在脑后）、猫耳×2、蓝挑染、金耳钉×2、藏青手套
  （左手）、雨伞（右手持：银伞柄 + 藏青握把 + 黄伞面锥 r 0.22 +
  银伞尖）。

## 关键尺寸与检查点

- 雨衣 vs 毛衣：z 1.20 处 rx 间隙 0.012、ry 0.012；z 0.90 处 0.014/0.018。
- 腰带 vs 雨衣：z 0.94/0.88 处 rx 0.008、ry 0.008（037 教训：ry 也要查）。
- 袖口环 r 0.105 vs 袖筒末端 0.096、vs 袖筒 s=0.60 处 0.0986（036 v3/037
  教训：只查末端会漏顶环）。
- 雨帽：檐底 z 1.608 vs 眼线 1.525（032 教训：檐不能挡眼）；帽带两环
  rx/ry 均比帽顶椭球面大 0.006（031 v3 教训：帽顶中心 y +0.01，ry
  要按 +y 侧表面算）；雨滴底 z 1.662 在帽带顶环 1.66 之上。
- 兜帽：背部弧面 15°–165°，z 1.44 处 rx 比雨衣大 0.010、比毛衣大 0.034；
  顶环 z 1.52 在雨衣顶沿 1.50 之上、藏在发后。
- 雨伞：伞柄从右手腕 (0.406, 0, 0.675) 沿 (0.553, -0.352, 0.755) 斜出
  0.70 米（与臂轴上延夹角 48°，不在前臂上穿袖而出），伞面中心
  (0.793, -0.246, 1.204)，锥面 r 0.22 → 0.02、高 0.10，伞尖 z 1.304。
  伞面底沿离雨衣椭球面：椭圆归一化值 2.171（>1.15 才算过）；
  伞面底沿离右袖轴线 0.302 米、袖筒半径 0.119，净空 0.183 米；
  伞柄在 z 0.90 处离雨衣椭球面归一化值 1.963（>1.15 才算过）。
- 雨靴：靴筒 z 0.50–0.02、靴底楔顶 0.105/0.055 盖住人偶脚掌顶
  （036 v1 教训）；靴底 z=0.0 落地（013 教训）。
- 雨滴凸起约 0.015 米（0.005–0.030 合格带）；褶裥脊高 0.022 米。
- 面数目标 ≤1500 面，N-gon 尽量为 0；人物占画面约 70%。
