## 角色故事

她是拉亥罗伊机甲的驾驶员，衣服就是她和机器之间的接口：胸甲上有
通风口和状态灯，背带把她固定在驾驶舱里，头盔上的天线是她和机甲
说话的线。橙色是机甲启动时的颜色——她一穿上这身，机甲就知道她来了。
靴子要够高：驾驶舱的踏板又冷又硬，膝盖要垫着，摔下来也不能疼。

## 线路与融合变量

- 线路：鸣潮式机能风 techwear（DESIGN.md：修身合体、哑光面料、
  黑白打底 + 亮色点缀、绑带与扣具、地区衣橱）——先定地区再定剪裁：
  拉亥罗伊机甲驾驶服，飞行服 + 胸甲 + 背带 + 头盔，一眼能读出
  “开机器的人”。
- 融合变量只改一个：**配色走机甲冷调**（炭黑 + 岩灰 + 米白头盔，
  橙色点缀），廓形保持机能风修身贴合，不用原神式层叠拖摆与
  大面积高饱和；头盔是全套唯一的米白大块面，是驾驶员的身份标记。

## 廓形

- **飞行服 + 胸甲**：炭黑飞行服从肩到腰修身（0.282→0.258），
  岩灰胸甲只罩胸段（z 0.95–1.30，0.300→0.290），上半身岩灰、
  下半身炭黑，远看就是“一台站着的机器”。
- **背带**：橙色竖带 + 弧形横带压在胸甲上，是全套最亮的一笔；
  横带走椭圆弧面（不用直盒，避免两端漂浮），竖带沿椭圆面法向
  微倾贴合（003/015 直盒贴曲面的教训：贴片必须算法向）。
- **头盔**：米白球壳是全套唯一的浅色大块面，橙面罩横在眼位，
  天线从右上斜出——三件加起来，一眼就知道这是驾驶员。
- **整体剪影**：修身贴合无拖摆，人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

## 沿用 001 v2 / 002 / 003 / 004 / 005 / 007 / 008 / 009 / 011 / 014 / 015 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；人偶最简五官：两只眼睛。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片/圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
- 挂件要放在看得见的位置（008 膝盘被裙摆挡住的教训）：
  胸灯放正面中央、通风口放左胸、膝垫放膝前、大腿束带放相机侧右大腿。
- 同色浮雕看不见（003 的教训）：通风口用炭黑压在岩灰胸甲上、
  胸灯用橙压在岩灰胸甲上、背带用橙压在岩灰胸甲上，靠色差读出层次。
- 底座不建赤脚（008 的教训）：裤管到地面 + 楔形脚掌，高筒靴盖住
  裤管与脚掌，脚不悬空。
- **013 质检的教训**：靴掌楔形中心 z=0.0 落地（011 的靴底悬空 0.02 米）；
  腰带下沿须比同高飞行服宽——本轮腰带上窄下张（0.288→0.298），
  下沿比同高飞行服宽 0.032。
- 相机侧配饰才看得见（008 圆盾的教训）：大腿束带、腰包放相机侧（+x / -y 前侧）。
- **曲面贴片必须算法向（本轮新点）**：胸甲是椭圆曲面，直盒贴上去
  两端会漂浮（015 围巾尾/口袋巾是平面胸，015 的算法不适用）；
  本轮通风口、背带竖带、腰包一律用 front_panel() 按椭圆面法向算
  中心与绕 Z 旋转，嵌入 0.003；横带走椭圆弧面管，不用直盒。
- **头盔遮住头发与眼睛**：人偶黑发与双眼仍建（底座标准），头盔
  球壳盖住，面罩是正面辨识标记；颈封只露头盔下缘一圈。
