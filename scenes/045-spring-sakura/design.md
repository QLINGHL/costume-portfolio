# 045 异环式都市时装 · 春日樱花套装

## 设计说明

- **灵感来源**：异环式都市时装第十一件——春日场景方向。学院 / 居家 /
  运动 / 街头 / 通勤 / 夜行 / 夏日 / 冬日 / 秋日 / 雨天矩阵里春日首次
  做，四季补齐。春日是都市日常里最轻盈的一面：樱粉开衫 + 百褶裙，
  手里一枝樱花，樱花枝是第七种手持物（039 托叶第五、040 雨伞第六之后）。
- **廓形**：变量是短款 + 裙装。樱粉短款开衫到腰 z 0.92（039/040 中长
  风衣到大腿中部的廓形变量），前开襟露奶油白高领毛衣；下身不用长裤，
  改藏青百褶裙到膝 z 0.35（039/040 长裤的变量）+ 奶油白过膝袜 +
  樱粉乐福鞋。开衫短、裙摆张，上下轻重反过来，读作春装。
- **配色**（主色 3 个 + 1 个点缀色；sRGB hex → linear，写死，v1 洗淡
  的根因就是把 sRGB 值当 linear 用）：

  | 角色 | sRGB hex | linear RGB | 用途 |
  | --- | --- | --- | --- |
  | 樱粉 | #F4A7B9 | (0.905, 0.386, 0.485) | 短款开衫、贝雷帽、乐福鞋 |
  | 藏青 | #1B2A4A | (0.011, 0.023, 0.068) | 长袖、腰带、帽带、百褶裙、樱花枝干、手套 |
  | 奶油白 | #F5EFE0 | (0.913, 0.862, 0.744) | 高领毛衣、袖口、过膝袜 |
  | 深樱红（点缀） | #D94F70 | (0.694, 0.078, 0.162) | 樱花纹×5、帽上樱花、枝上樱花×3 |
  | 金 | #C9A227 | (0.584, 0.361, 0.020)，metallic 0.6 | 腰扣、鞋扣、耳钉、樱花花心 |
  | 肤色 / 黑发 / 眼 | — | (0.694, 0.381, 0.209) / (0.011, 0.011, 0.015) / (0.003, 0.003, 0.003) | 人偶底座 |

- **纹样**：樱花纹×5 + 帽上樱花×1 + 枝上樱花×3，几何体呈现——新做法
  五瓣扁平贴片：每瓣两三角（瓣尖 r 0.032、瓣侧 0.55r、±20°），
  15 面/朵（花瓣 10 三角 + 金花心 5 三角，花心沿法向抬 0.002）。
  贴片离衣面 0.006，靠构造绕序定法向，fix_normals 永不跑扁平贴片
  （039 星形贴片教训）。毛衣前胸 3 朵（270° z 1.32；262°/278°
  z 1.02），开衫前襟边 2 朵（225°/315° z 1.10，落在开襟楔边外
  15°，不悬在开襟空处），贝雷帽正面 1 朵（300° z 1.70，039 帽针
  做法）。樱花纹是全线首次的纹样做法（此前是星形贴片 / 云纹 /
  雪花 / 波纹环 / 雨滴）。
- **褶裥**：百褶裙立体褶裥片×8（026/030/032/036/039 同款闭合薄
  solid，内沿离裙面 0.004、外沿 0.026），裙面是闭合筒（无开襟），
  褶裥可布满整圈：角度 170/200/230/260/290/320/350/20（含正面
  260°/290° 两道），行 z 0.55/0.45/0.35。
- **部件清单**：樱粉短款开衫（前开襟 arc 300°–600°，3 环，
  z 1.50–0.92）、奶油白高领毛衣（4 环，z 1.50–0.95）、樱花×5、
  褶裥×8、藏青腰带（z 0.98–0.92）+ 金腰扣、藏青长袖×2 +
  奶油白袖口×2、藏青百褶裙（3 环，z 0.95–0.35，外张）、
  奶油白过膝袜×2（z 0.35–0.06）、樱粉乐福鞋×2（鞋楔 + 鞋身 +
  金鞋扣）、樱粉贝雷帽（039 做法）+ 藏青帽带（v3 底环 0.230，
  044 已验证）+ 帽上樱花、猫耳×2、蓝挑染（042 验证位置
  (0.11,-0.175,1.44)）、金耳钉×2、藏青手套（左手）、樱花枝
  （右手持：藏青枝干 + 深樱红樱花×3）。

## 关键尺寸与检查点

- 开衫 vs 毛衣：z 1.20 处 rx 间隙 0.035、ry 0.018；z 0.92 处 0.044。
- 腰带 vs 开衫：z 0.98/0.92 处 rx 0.0071/0.007、ry 0.0076/0.007
  （037 教训：ry 也要查）。
- 袖口环 r 0.105 vs 袖筒末端 0.096、vs 袖筒 s=0.60 处 0.0986（036
  v3/037 教训：只查末端会漏顶环）。
- 百褶裙：顶环 z 0.95 rx 0.258 藏在毛衣下摆（0.264）内 0.006、无露肤；
  裙摆 z 0.35 rx 0.335，张过双腿外沿 0.230；裙摆底沿 z 0.35 与过膝袜
  顶 z 0.35 对接、无露肤。
- 过膝袜 vs 腿：z 0.20 处 0.0979 vs 0.0866，间隙 0.0113。
- 乐福鞋：鞋身 z 0.16–0.03 r 0.106/0.104 vs 过膝袜 0.0974，间隙
  0.0086；鞋楔 hx 0.100 vs 人偶脚掌 0.095；鞋底 z=0.0 落地（013 教训）。
- 贝雷帽：039 同款几何（球 r 0.26、中心 (0,0.01,1.68)、z 压 0.42），
  帽带三环 0.2616/0.2479/0.230（044 v3 底环，刻面环顶点三维距离
  0.0072）；帽底 1.571 在眼线 1.525 之上（032 教训：帽不能挡眼）。
- 樱花枝：枝干从右手腕沿 (0.553,-0.352,0.755) 斜出 0.55 米（040 雨伞
  方向，48° 离臂轴，不穿袖而出）；枝上 3 朵樱花在 s 0.30/0.42/0.52，
  法向朝前 (0,-1,0.35)；枝干在 z 0.90 处离裙面椭圆归一化值 2.28
  （>1.15 才算过）；中朵离袖轴 0.313、袖筒半径 0.110、瓣半径 0.030，
  净空 0.173。
- 挑染沿用 042 验证位置 (0.11,-0.175,1.44)，可见 22/26、凸起 0.0397
  （0.005–0.045 合格带内）。
- 面数目标 ≤1500 面，N-gon 尽量为 0；人物占画面约 70%。
