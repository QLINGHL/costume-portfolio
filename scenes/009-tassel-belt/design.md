# 009 流苏腰带与配饰包 · Tassel Belt & Accessory Pack

服装部件包：流苏腰带 + 金币挂件 + 玉佩 + 臂环 + 腰侧铃铛。
009 号作品，按 001 v2 确立的组件化流程（L1 → L2 → L3）从零制作。
这是一件**部件包**，不是整套服装：腰带、流苏、挂件、臂环做成
可拆分的独立组件，设计上可复用到 001 云纹战袍、002 机能猎手、
005 赛博汉服等已有套装上——腰带换上去就是另一套腰线。

## 角色故事

行者的腰带——走路时流苏会晃，金币会响，玉佩会亮。
深红腰带讲的是“走过很多地方”（红是磨损不掉的颜色），
八道流苏是八次远行的记号（中间最长、两边渐短，像一路走来的
脚印），两枚金币是路费（挂在腰上随时能摸到），中央玉佩是
护身符（最大、最亮、挂在正中间），臂环是出发前戴上的
（金环 + 玉钉，左右对称），腰侧一枚小金铃是报平安的
（走一步响一声，队友听得见你）。

## 线路与融合变量

- 线路：原神式层叠幻想的配饰分支（DESIGN.md：层叠与配饰、
  角色专属挂件）+ 鸣潮式机能风的扣具语言（腰带、绑带、
  战术扣具是统一视觉语言）。
- 融合变量只改一个：**廓形保持配饰包**（腰带 + 垂饰 + 臂环，
  不做上身、不做裙摆），配色走原神的高饱和层叠（深红 +
  金 + 玉），不用机能风的黑白打底；挂件的“讲故事”逻辑
  取原神，扣具的“金边收边”取鸣潮。

```
L1 小组件（每个单独建模、单独检查廓形比例）

├── 玉佩（金链 + 金底圆盘 + 玉圆盘，正面中央 270°，全包最大挂件）
├── 腰侧金铃（金链 + 金铃，右前 30°，相机侧看得见）
├── 臂环左/右（金色臂环 + 玉钉，绕上臂一周）

├── 腰带 = 腰带主体 + 腰带金边上/下 + 腰带金扣
├── 流苏组 = 流苏×10（检查相邻穗间距、穗底不碰地面）
├── 挂件组 = 金币挂件×2 + 玉佩（检查金币与玉佩层叠间隙、
│   金币与邻近流苏不相交）
├── 臂环组 = 臂环左/右（检查臂环与手臂间隙、玉钉浮雕）
└── 腰侧 = 腰侧金铃（检查金铃与手臂间隙）
```

## 廓形

- **腰带**：深红宽腰带是全包的横向主线，腰围一圈，金边上下
  收住，金扣压在正面中央——腰线一眼就定住。
- **流苏**：前弧两组各 4 道，中间最长、两边渐短，穗尖微向外张，
  像裙摆的褶裥一样有节奏；两侧各 1 道短穗，侧面也有东西看。
- **挂件**：中央玉佩最大（直径 0.116 米），两枚金币分列两侧
  （直径 0.064 米），一大两小、中间高两侧低，挂件组本身就是
  一个小小的金字塔构图；金币比玉佩多向外 0.009 米，层叠在前。
- **臂环与金铃**：左右臂环对称，玉钉朝外；右侧腰侧一枚金铃，
  是 3/4 正面（相机侧）的第二个亮点。
- **整体剪影**：上身留白（只有底衬），视觉重心全压在腰线——
  腰带横贯、流苏下垂、挂件居中，人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

| 角色 | 颜色 | sRGB hex | linear RGB（脚本用） | 粗糙度 / 金属度 | 用处 |
|---|---|---|---|---|---|
| 主色 1 | 深红 | #A4161A | (0.371, 0.008, 0.010) | 0.8 / 0.0 | 腰带主体、流苏穗 |
| 主色 2 | 金 | #D4A017 | (0.658, 0.352, 0.009) | 0.35 / 0.7 | 腰带金边、金扣、流苏金珠、金币、金链、玉佩金底、臂环、金铃 |
| 主色 3 | 象牙白 | #F2E8D5 | (0.888, 0.807, 0.665) | 0.85 / 0.0 | 展示底衬（贴身短袍） |
| 点缀 | 玉绿 | #2E8B6A | (0.027, 0.258, 0.144) | 0.5 / 0.0 | 玉佩、金币玉钉、臂环玉钉 |
| 肤色 | — | #D9A67E | (0.694, 0.381, 0.209) | 0.7 / 0.0 | 人偶（沿用 008 的肤色） |
| 发色 | — | #2A2D33 | (0.023, 0.026, 0.033) | 0.7 / 0.0 | 短发（沿用 002 的发色） |
| 眼睛 | — | #0A0A0A | (0.003, 0.003, 0.003) | 0.6 / 0.0 | 人偶最简五官 |

- 配色逻辑：深红腰带 + 金色五金是全包的主旋律，玉绿只占约 5%，
  是“护身符功能色”（玉佩、玉钉），三处玉绿上下呼应（玉佩居中、
  金币玉钉、臂环玉钉）；象牙白底衬只在腰带上下露一线，拉开明度。
- **流苏看得见的防线**：流苏用深红（#A4161A）做穗，金珠做顶，
  穗与底衬象牙白反差足够；穗是独立锥形管（不是平面），
  侧面看也有厚度；穗长中间 0.28、两边渐短，长度差本身就是纹样。

## 纹理（全部用几何体，不靠贴图——001 v2 的标准）

| 纹理 | 做法 |
|---|---|
| 流苏 | 每道独立锥形管（3 环、6 边，顶粗 0.013、尖细 0.008）+ 顶部金珠小盒，穗尖微向外张 0.012 米，几何呈现 |
| 金币 | 金色圆盘（12 边）+ 中央玉钉小圆盘（8 边），高出金币面 0.004 米 |
| 玉佩 | 金底圆盘（12 边，直径 0.116）+ 玉圆盘（12 边，直径 0.100），玉高出金底面 0.004 米 |
| 腰带金边 | 腰带上下沿各一圈金色细环，高出腰带面 0.004 米 |
| 腰带金扣 | 金色方盒，高出腰带面 0.012 米 |
| 臂环玉钉 | 玉色小球嵌在臂环外侧，高出臂环面 0.026 米 |
| 金铃 | 金色小球（8 边、4 环）+ 金链，金链挂在腰带底边 |

## 面数目标（配饰包 ≤800，目标约 500）

金币挂件约 26/枚 ×2 = 52、玉佩约 30、腰侧金铃约 38、臂环约 26/只 ×2 = 52。

## 沿用 001 v2 / 002 / 003 / 004 / 005 / 007 / 008 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；人偶最简五官：两只眼睛。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片/圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
- 挂件要放在裙摆/腰带下沿之下才看得见（008 v1 膝盘被裙摆挡住的教训：
  金币与玉佩挂在腰带底边 z=0.70 之下，链长留足，盘顶接住链底）。
- 相机侧挂件才看得见（008 v1 圆盾绑左臂只露一个边的教训：
  金铃挂在右侧 15°——相机侧；玉佩挂正面中央 270°，不偏不倚）。
- 同色浮雕看不见（003 的教训）：玉佩用玉绿盘压在金底盘上，
  金币用玉钉点在金盘中央，靠色差读出层次，不靠 0.004 浮雕。
- 底座不建赤脚（008 的教训）：009 无鞋，腿管延长到地面 + 肤色
  楔形脚掌接住，脚不悬空。

## 返工记录（v1 → v2，轮次内）

- 金币 262°/278° → 250°/290°：首渲两枚金币与中央玉佩投影重叠，
  像玉佩长了两只“耳朵”，分不清是独立挂件；移到 250°/290° 后
  与玉佩边缘留 0.028 米空隙，一大两小的金字塔构图才读出来；
  流苏组随之从两组各 4 道改为各 3 道（212°–236° / 304°–328°），
  给金币让出位置。
- 金币链 0.13 → 0.15 米、盘径 0.032 → 0.036 米：挂件组里金币
  太小看不清，加大一档并略放低，与玉佩拉开高度差。
- 金铃 15° → 30°：首渲金铃藏在右手后只剩一个金点；移到右前
  30° 后脱离手臂遮挡，腰侧看得见。
- 流苏穗加粗（顶 0.013 → 0.015、尖 0.008 → 0.009）：首渲穗太细
  像红线，加粗后才有“穗”的体量。
- 扁平贴片排除规则改按基础名匹配：v1 用 endswith("Disc") 排除
  法向检查，Blender 把第二枚金币的盘重命名为 CoinDisc.001，
  3 个面被误翻、右侧金币发暗；改按 name.split(".")[0] 匹配基础名，
  v2 不再误翻。
