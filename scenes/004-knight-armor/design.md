# 004 骑士铠甲礼服 · Knight Armor Dress

蒙德风骑士铠甲礼服：钢甲胸甲 + 白裙 + 红结 + 深蓝披风。
004 号作品，按 001 v2 确立的组件化流程（L1 → L2 → L3）从零制作。

## 角色故事

蒙德西风骑士团的骑士——铠甲首先是职责：胸甲护住要害、肩甲挡住
劈砍、臂铠护住小臂、战靴护住小腿；白裙与红结讲的是这个人：
白裙是蒙德的干净与体面，红结是骑士的信物，披风是出城巡逻时
挡风挡雨的。每一件东西都有用途，不为装饰而装饰。

## 线路与融合变量

- 线路：原神式层叠幻想（DESIGN.md 线路一，蒙德地区：欧式骑士、
  蓝白配色、高领、皮靴——琴的骑士团配色就是这条线的范本）。
- 融合变量只改一个：廓形保持原神层叠不变，配色用钢银 + 白 +
  藏青三档，红结只做点缀（不用 techwear 绑带、不用异环都市剪裁）。

## 廓形

- **上身**：胸甲挺括、肩线平直，肩甲半球向外张出骑士的宽度；
  白色立领从胸甲上方露出，红结压在胸甲正中，是全套视觉中心。
- **下身**：白裙自腰部外张、拖至脚面，八道淡钢蓝褶裥绕裙一周，
  藏青裙边收底；战靴只露靴头与靴筒一点，靴口金箍点亮脚踝。
- **披风**：藏青披风自肩后垂下，遮住大半个背部，行走感靠披风
  下摆的外张；金发马尾垂在披风之外，不穿帮。
- **整体剪影**：上身挺括、下身舒展，肩甲 + 披风拉出横向与纵向
  两条线；人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

- 配色逻辑：钢银、白、藏青三档靠明度与金属感拉开层次
  （铠甲金属反光、白裙哑光、藏青深沉），红结只占约 5%，
  是“信物点睛色”。
- **钢甲发灰的防线**：胸甲金属度 0.85 + 粗糙度 0.35（抛光钢），
  白裙 0.85 哑光、藏青 0.75，三档材质一望即分；层间隙 ≥0.005 米
  保证阴影缝；轮廓光不能省。

## 纹理（全部用几何体，不靠贴图——001 v2 的标准）

| 纹理 | 做法 |
|---|---|
| 胸甲横带 | 2 条横向金色弧带，高出胸甲面 0.003 米，宽 0.02 米（v1 同色钢带在渲染里完全看不见，已改金色，靠色差读出） |
| 胸甲金边 | 胸甲底边一圈金色弧带 |
| 肩甲徽章 | 每侧肩甲一个金色圆片（徽章），贴在肩甲外侧 |
| 裙摆褶裥 | 8 条竖向凸条绕裙一周，每条高出裙面 0.006 米、宽 0.032 米，\n  用淡钢蓝（#C7D0DD → linear (0.571, 0.631, 0.723)）做褶裥，\n  以色差读出立体感（003 的教训：同色褶裥在渲染里看不见） |
| 红结 | 结环×2（旋转方块）+ 结心小球 + 垂带×2，全部几何体，\n  压在胸甲正中，高出甲面约 0.016 米 |
| 披风肩扣 | 前肩两枚金色圆片，固定披风 |
| 战靴靴口箍 | 靴筒顶部一圈金色环带 |
| 马尾发圈 | 金色小圆柱环，束住马尾根部 |

## 面数目标（整套 ≤1200，目标约 1000）

白裙约 70（含立领）、胸甲约 70（含横带+金边）、肩甲约 130、
白袖+臂铠约 110、腰带+红结约 70、披风约 60、褶裥约 25、
裙边约 25、战靴约 105、金发约 135、五官约 30。合计约 835。

实测（2026-11-21 05:10 轮次）：整套 **641 面**（三角 104 + 四边 537，
N-gon 0），L2 ALL PASS、L3 PASS，FRAME_FRACTION 0.700，目视通过。
低于估算主因是肩甲球面（40 面/个）与发顶未计入服装面数。

## 沿用 001 v2 / 002 / 003 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；底座不建赤脚，脚由战靴提供。
- 人偶最简五官：两只眼睛 + 红唇，3/4 正面一眼认出正面。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片/圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
- 褶裥必须用比底色深一档的颜色（003 的教训，同色 0.004 浮雕看不见）。
- 马尾垂在披风之外：马尾根部 y 值要大于披风背部 y 值，不穿帮。

## 返工记录（v1 → v2，2026-11-21 05:10 轮次内）

v1 首渲（641 面，L3 全过，FRAME_FRACTION 0.614）目视发现 4 处问题，
只返工对应组件、不推倒整件：

1. L2 两项 FAIL：臂铠腕箍 vs 白袖间隙 0.002、臂铠末端 vs 手间隙
   0.003，均小于 0.005——腕箍半径 0.102 → 0.108，臂铠末端半径
   0.088 → 0.095（腕部微张）。
2. 红结太小、读成胸前小红十字——结环 0.09×0.05 → 0.12×0.07、
   结心半径 0.022 → 0.028、垂带 0.035 → 0.045 宽，旋转角 0.6 → 0.45
   并外移防结环角穿进胸甲。
3. 胸甲横带同色钢带在渲染里看不见——改金色，靠色差读出。
4. 披风正面几乎看不见、人物只占画面 61%——披风各环 rx 加宽
   0.02~0.03（下摆 0.46），相机拉近至 (1.93, -2.94, 1.35)，目标占比 ~70%。
