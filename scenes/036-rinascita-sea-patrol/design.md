## 角色故事

她是黎那汐塔近海巡逻队的一员——深青短款防风外套罩在炭黑潜水服
外面，荧光青波纹环是海浪的标志，胸口一枚金锚徽，腰间战术腰带挂
着一圈荧光青绳索。珍珠白水手帽顶着荧光青护目镜，帽檐压得很低，
一缕荧光青挑染从帽檐下露出来；膝盖上有深青护垫，脚下是炭黑高筒
靴，右手托着一枚金罗盘——巡海者的眼睛永远先看海，再看罗盘。

## 线路与融合变量

- 线路：鸣潮式机能风 techwear（DESIGN.md：修身合体、黑白打底 +
  亮色点缀、绑带与扣具、地区衣橱、服装即护照）——先定地区再定
  剪裁：黎那汐塔近海，巡海者工作制服，深青 + 珍珠白 + 炭黑，
  一眼能读出「海上巡逻的人」。
- 融合变量只改一个：**廓形改短款外套**（防风外套裁到腰 z 0.86，
  不用 032 长款羽绒大衣的及膝廓形、不用 023 嘉年华贵族的大摆裙
  廓形、不用 024 黑海岸守望者的修身长衫廓形），鸣潮线做法保持
  （炭黑打底 + 一个亮色点缀、绑带扣具、几何纹样）。
- 与 023 的区别（023 已是奶油白 + 紫罗兰 + 鎏金的嘉年华贵族）：
  023 是礼服——大摆裙、蕾丝领、羽毛礼帽、半面金面具；036 是
  工作制服——短款防风外套、潜水服、战术腰带、膝垫、高筒靴、
  水手帽、护目镜、罗盘，廓形、头饰、下装、鞋、手持物全部换新，
  紫罗兰改成深青、鎏金只做扣与徽、荧光青是本轮的亮色。

## 廓形

- **深青短款防风外套 + 炭黑潜水服**：外套是全身最大的色块
  （前开襟、裁到腰、荧光青波纹环），炭黑潜水服从开襟里透出来，
  金锚徽 + 荧光青拉链齿在开襟正中，是本轮的廓形主角。
- **珍珠白水手领 + 水手帽**：白领环 + 肩后披领在颈肩叠了两层白，
  白帽顶 + 深青帽带 + 白帽檐 + 荧光青护目镜在头顶叠了四层，
  是头部的视觉落点。
- **炭黑战术腰带 + 荧光青绳圈**：腰带在外套下摆之下整圈可见，
  金腰扣在前中，绳圈在腰带之下第二圈——短款外套的落点。
- **珍珠白长裤 + 深青膝垫 + 炭黑高筒靴**：裤、垫、靴三层叠在腿上，
  荧光青膝条是腿部的亮色，鞋底落地。
- **金罗盘**：托在右手（相机侧）掌心，是手部唯一的配饰。
- **整体剪影**：水手帽 + 短款外套 + 战术腰带 + 膝垫高筒靴，
  人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算
