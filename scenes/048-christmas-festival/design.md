# 048 异环式都市时装 · 圣诞节日套装

## 设计说明

- **灵感来源**：异环式都市时装第十二件——节日/圣诞场景方向。学院 /
  居家 / 运动 / 街头 / 通勤 / 夜行 / 夏日 / 冬日 / 秋日 / 雨天 / 春日
  矩阵里节日首次做，12 月圣诞季贴合（039 秋日、032 冬日同款季节逻辑）。
  圣诞是都市日常里最热闹的一面：圣诞红大衣 + 雪白毛领 + 圣诞帽，
  手里一个礼物盒，礼物盒是第八种手持物（039 托叶第五、040 雨伞第六、
  045 樱花枝第七之后）。
- **廓形**：变量是长款 + 圣诞件。圣诞红长款大衣到膝 z 0.45（032 长款
  大衣到膝 z 0.42 的同款长度，变量是圣诞红 + 雪白毛领 + 圣诞帽；
  039 中长风衣到大腿中部 z 0.58、045 短款开衫到腰 z 0.92 的廓形变量），
  前开襟露雪白高领毛衣；下身藏青长裤 + 圣诞红短靴。大衣长、靴口毛绒、
  帽尖翻折，读作节日装。
- **配色**（主色 3 个 + 1 个点缀色；sRGB hex → linear，写死，v1 洗淡
  的根因就是把 sRGB 值当 linear 用）：

  | 角色 | sRGB hex | linear RGB | 用途 |
  | --- | --- | --- | --- |
  | 圣诞红 | #C1272D | (0.533, 0.020, 0.026) | 长款大衣、短靴、圣诞帽、礼物盒 |
  | 雪白 | #F7F3E8 | (0.930, 0.896, 0.807) | 高领毛衣、袖口、毛领、帽边、靴口、绒球 |
  | 墨绿 | #1E4D3B | (0.013, 0.074, 0.044) | 腰带、手套 |
  | 藏青 | #1B2A4A | (0.011, 0.023, 0.068) | 长袖、长裤 |
  | 金（点缀） | #C9A227 | (0.584, 0.361, 0.020)，metallic 0.6 | 圣诞星×5、帽上金星、腰扣、靴扣、耳钉、礼物丝带 |
  | 肤色 / 黑发 / 眼 | — | (0.694, 0.381, 0.209) / (0.011, 0.011, 0.015) / (0.003, 0.003, 0.003) | 人偶底座 |

- **纹样**：金色圣诞星×5 + 帽上金星×1，几何体呈现——039 五角星形
  扁平贴片做法（10 三角扇形，尖角 r、外角 0.45r），贴片离衣面
  0.006，靠构造绕序定法向，fix_normals 永不跑扁平贴片（039 星形
  贴片教训）。毛衣前胸 3 颗（270° z 1.32；262°/278° z 1.02），
  大衣前襟边 2 颗（225°/315° z 1.10，落在开襟楔边外 15°，不悬在
  开襟空处），圣诞帽锥面 1 颗（正面 z 1.75，锥面法向 (0,-0.826,
  0.564)）。星形贴片在 039 是枫叶纹的形状载体，本轮第一次读作
  圣诞星。
- **褶裥**：大衣下摆立体褶裥片×8（026/030/032/036/039 同款闭合薄
  solid，内沿离衣面 0.004、外沿 0.026），大衣是前开襟（240°–300°
  开口），褶裥只布开口外：角度 170/200/230/320/350/20/50/110，
  行 z 0.65/0.55/0.45。
- **圣诞帽**：全线首次。红锥体（底环 z 1.64 r 0.235、顶 z 1.94
  r 0.030，12 边）+ 翻折帽尖（短管从锥顶向前下方折出 0.13 米）
  + 白绒球（r 0.035，盖住帽尖管口）+ 雪白帽边（z 1.64–1.59，
  r 0.245/0.248，帽边底沿 z 1.59 在眼线 1.525 之上 0.065）。
  锥体底环 r 0.235 相对发面（z 1.64 处 rx 0.2073）留 0.028；
  锥面在 z 1.66 处 r 0.2213 相对发面 0.1949 留 0.0264（发面最宽处
  附近仍 ≥0.005——锥体不能按底环一个高度验，要验 z 1.66 这一档）。
- **毛领**：雪白毛领（z 1.54–1.48，r 0.325/0.320），前开弧
  （arc 300°–600°，与大衣同款开襟做法），套在大衣领口外：底环
  相对大衣顶环（z 1.48 处 rx 0.312）留 0.008，读作盖在大衣肩上
  的毛绒领圈。v2 修正：v1 是整圈，前面横在眼睛高度读作蒙眼布、
  挡住双眼，改前开弧后正面不再横过面部。
- **部件清单**：圣诞红长款大衣（前开襟 arc 300°–600°，5 环，
  z 1.50–0.45）、雪白高领毛衣（5 环，z 1.50–0.62）、金色圣诞星×5、
  褶裥×8、雪白毛领、墨绿腰带（z 0.94–0.88）+ 金腰扣、藏青长袖×2 +
  雪白袖口×2、藏青长裤（3 环，z 0.62–0.34）、圣诞红短靴×2（靴筒 +
  鞋底楔 + 雪白靴口 + 金靴扣）、圣诞帽（红锥 + 翻折帽尖 + 白绒球 +
  雪白帽边 + 帽上金星）、蓝挑染（042 验证位置 (0.11,-0.175,1.44)）、
  金耳钉×2、墨绿手套（左手）、圣诞礼物盒（右手持：红盒 0.07 +
  金丝带十字 + 金蝴蝶结）。

## 关键尺寸与检查点

- 毛衣 vs 躯干：z 1.28 处 0.2805 vs 0.270（间隙 0.0105）；z 0.95 处
  0.265 vs 0.240（间隙 0.025）。
- 大衣 vs 毛衣：z 1.20 处 rx 0.310 vs 0.2767（0.033）；z 0.90 处
  0.308 vs 0.2627（0.045）；ry 同查。
- 毛领 vs 大衣：z 1.48 处 0.320 vs 0.312（间隙 0.008）。
- 腰带 vs 大衣：z 0.94 处 rx 0.318 vs 0.3083（0.0097）、ry 0.168 vs
  0.1603（0.0077）；z 0.88 处 rx 0.317 vs 0.3084（0.0086）、ry 0.167
  vs 0.1601（0.0069）。
- 袖口环 r 0.105 vs 袖筒末端 0.096、vs 袖筒 s=0.60 处 0.0986（036
  v3/037 教训：只查末端会漏顶环）。
- 长裤 vs 腿：z 0.52 处 rx 0.2417 vs 腿 0.1023（039 同款量法）。
- 短靴：靴筒 vs 腿 z 0.20 处 0.118 vs 0.0866；雪白靴口 vs 靴筒
  0.124 vs 0.118（0.006）；鞋底楔 0.102 vs 人偶脚掌 0.095；金靴扣
  浮雕 0.010；靴底 z=0.0 落地（013 教训）。
- 圣诞帽：红锥底环 z 1.64 r 0.235 vs 发面 0.2073（0.0277）；锥面
  z 1.66 r 0.2213 vs 发面 0.1949（0.0264）；帽边 z 1.59 r 0.248 vs
  发面 0.2236（0.0244）；帽边底沿 z 1.59 在眼线 1.525 之上 0.065
  （032 教训：帽不能挡眼）；帽上金星浮雕 0.006。
- 挑染沿用 042 验证位置 (0.11,-0.175,1.44)，顶 z 1.49 在帽边底沿
  1.59 之下，不顶穿圣诞帽（031 v1 教训）。
- 礼物盒：盒 0.07，中心在右腕前 (wx, wy-0.11, wz-0.05)；盒背
  面嵌进掌面 0.0085（读作握持，不漂浮）；盒顶角相对袖筒末端盖
  平面的轴向分量 +0.0198（在盖平面之外，不穿袖筒）。
- 面数目标 ≤1500 面，N-gon 尽量为 0；人物占画面约 70%。
- 猫耳省略：圣诞帽盖住双耳（031 遮阳帽同款处理）。
