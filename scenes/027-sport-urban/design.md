## 角色故事

她是异环都市里每天清晨五点半就出门晨跑的人，耳机里放着同一张
歌单，跑完三公里在便利店门口买一瓶冰水——腰包里永远装着钥匙、
一张交通卡和一根备用的橙色发圈。藏青连帽衫是她买过最合身的一件，
拉链拉到顶能挡住下半张脸；白袋鼠兜里揣着双手，橙色抽绳随着步子
一晃一晃；运动裤两侧的橙条是她挑这条裤子的唯一理由；白运动鞋的
橙鞋底在柏油路上踩出轻响。猫耳是她晨跑时偷偷戴的，风纪委员本人
也想可爱一点——不对，那是 026 的人。这是另一个人：她只是觉得，
跑步的时候，耳朵尖上有点重量，风才有形状。

## 线路与融合变量

- 线路：异环式都市时装（DESIGN.md：现代都市日常服、职业一眼可辨、
  现实配色 + 一个亮色点缀、版型合体修身、非人元素点缀）——先定
  场景再定元素：都市晨跑者，藏青 + 白 + 橙点缀，一眼能读出
  “刚跑完步、正在便利店门口喝水的人”。
- 融合变量只改一个：**廓形改运动风**（连帽衫 + 兜帽 + 袋鼠兜 +
  运动长裤 + 高帮运动鞋，不用 015 的修身风衣廓形、不用 025 的
  oversized 街头廓形、不用 026 的学院风修身套装廓形），配色逻辑
  与面料做法保持异环线（现实配色打底 + 一个亮色点缀，橙是异环

## 廓形

- **藏青运动连帽衫 + 橙拉链条 + 白袋鼠兜 + 藏青运动长裤 +
  白高帮运动鞋**：上身微宽松（0.300→0.290，比 026 修身西装宽
  0.005），兜帽在脖颈后张开，袋鼠兜在胸前下部，运动裤直筒微收，
  远看就是“便利店门口一道藏青白影子，橙色拉链和腰包是唯二的暖色”。
- **橙拉链条 + 黄拉链头 + 橙抽绳**：胸前中线唯一的竖向暖色，
  是全套的视觉锚点，一眼可辨。
- **橙腰包 + 藏青腰带环**：橙腰包是全套最大的橙色块，压住前腰
  中央，025 的教训：藏青上的黑腰包成了小黑块——本轮腰包改橙色，
  配饰与底色拉开色差。
- **橙发带 + 橙腕带 + 橙袜圈 + 橙侧条纹 + 橙鞋底**：橙色在全身
  五处呼应（头、手腕、裤侧、袜口、鞋底），运动风的“全身配色
  呼应”做法。
- **藏青猫耳 + 蓝挑染**：非人元素点缀，猫耳藏青融进发色、蓝挑染
  是唯一的冷亮色，异环式“非人元素点缀”的收尾。
- **整体剪影**：微宽松连帽衫 + 兜帽 + 袋鼠兜 + 直筒运动裤 +
  高帮运动鞋，人物 3/4 正面，占画面约 70%。
