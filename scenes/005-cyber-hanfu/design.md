# 005 赛博汉服 · Cyber Hanfu

原创融合：汉服廓形（交领、宽袖、马面裙）+ 机能面料与五金 + 发光纹路 + 不对称剪裁。
005 号作品，按 001 v2 确立的组件化流程（L1 → L2 → L3）从零制作。

## 角色故事

未来都市的汉服修复师——汉服是身份，机能面料是工作服，发光纹路是衣服里的
能量回路。交领讲的是出身（汉服），宽袖讲的是手艺（修复师要活动自如的袖口
其实收了束口），发光回路讲的是时代（回路通电才亮，是工具不是装饰）：
胸前回路是身份识别码，袖口纹是工作状态灯，裙摆纹是夜间定位线。
每一件东西都有用途，不为装饰而装饰。

## 线路与融合变量

- 线路：原创融合（DESIGN.md：汉服廓形 + 鸣潮机能风面料/五金）。
- 融合变量只改一个：廓形保持汉服（交领、宽袖、马面裙）不变，面料与
  细节改成机能风（哑光深色 + 五金扣具 + 发光回路纹），不用异环都市剪裁、
  不用原神层叠披风。

## 廓形

- **上身**：交领 V 字压在胸前，回路纹沿 V 字两侧走；大袖衫修身，
  肩线平直，左肩一枚护甲打破对称。
- **袖**：宽袖自肩外张、袖口束口收窄，青色袖口纹是袖子的收口线；
  左臂一根绑带是全套唯一的绑带（002 的教训：绑带只留功能性的）。
- **下身**：月白马面裙自腰外张、拖至脚面，八道墨青裙褶绕裙一周，
  左长襟垂至膝下、右短襟只到大腿，不对称剪裁一眼可辨；裙摆青线收底。
- **整体剪影**：上身挺括、下身舒展，宽袖 + 长裙拉出汉服的纵向线，
  单肩护甲 + 不对称前襟拉出赛博的横向断点；人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

- 配色逻辑：墨青、月白、深灰三档靠明度拉开层次（袍深、裙亮、腰封
  居中），电光青只占约 5%，是“回路功能色”（身份码、状态灯、定位线），
  不是装饰色。
- **墨青一团糊的防线**：大袖衫哑光（粗糙度 0.85）、腰封/护甲半哑光
  （0.6）、五金金属（0.3 + 金属度 0.8）、发光纹自发光；月白马面裙
  在下身拉开明度对比；层间隙 ≥0.005 米保证阴影缝；轮廓光不能省。

## 面数目标（整套 ≤1200，目标约 1000）

中衣约 70、交领约 25、大袖衫约 70、宽袖约 130（含袖口纹）、
腰封约 60、马面裙约 70、裙褶约 25、前襟约 30、回路纹约 40、
单肩护甲约 60、绑带约 15、玉佩约 20、发簪约 10、长靴约 110、
短发约 60、五官约 30。合计约 825。

实测（2026-11-21 09:10 轮次）：整套 **547 面**（三角 54 + 四边 493，
N-gon 0），L2 ALL PASS、L3 PASS，FRAME_FRACTION 0.700，目视通过。
低于估算主因是交领带/前襟/裙褶用了贴合曲面的薄带片（每带仅 2–4 面）
而非实体管，宽袖与长靴的环数也比估算少。
返工（轮次内 v1 → v2）：首渲发现左袖口上方露出一小条人偶手臂顶盖
（宽袖开口朝上、顶盖透过开口可见）——宽袖管起点从肩点上移 0.06 米
盖住顶盖，重渲后消失；同时把设计里“右肩/右臂”纠正为“左肩/左臂”
（sx=+1 是人偶的左手侧、即镜头侧）。

## 沿用 001 v2 / 002 / 003 / 004 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；底座不建赤脚，脚由长靴提供。

  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
