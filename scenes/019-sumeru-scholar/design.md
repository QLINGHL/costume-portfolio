# 019 原神式层叠幻想 · 须弥雨林学者长袍

整套服装：原神式层叠幻想——须弥教令院的雨林学者长袍：叶绿长袍 +
金饰 + 奶油宽袖 + 叶纹 + 金环冠 + 草履。019 号作品，按 001 v2 确立的
组件化流程（L1 → L2 → L3）从零制作。BACKLOG 本轮已空，按 README
四方向自选：**原神地区衣橱新方向：须弥**（DESIGN.md：先定地区再定
元素，须弥对应雨林与学者文化，此前未做过）。

## 角色故事

她是教令院的年轻学者，住在化城郭的树屋里，白天在雨林里采标本，
晚上在灯下抄写草药图鉴。叶绿长袍是雨林的颜色，金饰是教令院的
徽记，胸前与裙上的叶纹是她亲手压制的标本，奶油宽袖方便她在书
桌与林间穿行，头顶的金环是学者身份的记号——环上那片小叶，是她
第一天进雨林时捡到的。

## 廓形

- **叶绿上身 + 奶油宽袖 + 叶绿大摆裙**：上身修身（0.290→0.275），
  长裙从腰向下张开（0.305→0.500），奶油宽袖与奶油罩裙前片在
  叶绿主调上提亮，远看就是“一株站在雨林里的金边绿叶”。
- **金 V 领带**：两条金领带沿上身曲面斜贴，胸前交叉成 V，
  学者长袍的标志，一眼可辨。
- **奶油罩裙前片**：奶油宽贴片盖在叶绿长裙正面中央，两侧金边条
  收边，是全套的视觉中心，也是 018 朱红袴前片思路的反向应用
  （018 是深色裙 + 浅色上身，019 是深色裙 + 浅色前片）。
- **深绿披肩**：只盖后背与双肩的弧面披肩，学者外袍的层次，
  正面不挡叶纹与金领带。
- **整体剪影**：宽袖 + 大摆裙 + 金环冠，人物 3/4 正面，
  占画面约 70%。
