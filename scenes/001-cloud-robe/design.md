# 001 云纹战袍套装 · Cloud-Pattern Battle Robe

璃月风层叠战袍，全套服装建模（001 号作品，服装建模管线验证件）。

## v2 重做原因（2026-11-20，用户看图后指出，全部属实）

- v1 造型就是几个直筒方块拼的：袍子直筒、袖子直筒、头是方块加棕色盖，没有布料感。
- 云纹完全看不见——名字叫云纹战袍，袍子上没有任何纹样。
- 颜色洗淡了：青黛发成浅青，朱红发成粉红。
- 构图：人只占画面中间一小块，四周大片空灰，地面横线生硬；正面/背面分不清，没有脸。
- **洗淡的根因已定位**：v1 把 sRGB 语义的色值直接当 linear 值喂给 Principled BSDF
  （如青黛 (0.16, 0.42, 0.40) 当 linear 用，显示出来是浅青）。v2 色值全部按
  sRGB hex → linear 换算后写死，脚本只用 linear 值。
- **制作方法纠正（2026-11-20，用户亲口）**：不许整件一次成型，按游戏服装的正规
  制作流程——一个小组件合成一个大组件，一步一步组装：L1 小组件 → L2 中组件 →
  L3 大组件，每级单独验证再往上组装。

## 组件树（v2，组件化制作流程）

```
L1 小组件（每个单独建模、单独检查廓形比例）
├── 内层贴身袍、主袍、主袍裙摆金边
├── 立领、领口金边、前襟（含 2 颗盘扣）
├── 腰封、金扣（金板 + 金钉）
├── 宽袖左、宽袖右、袖口金边左、袖口金边右、袖口云纹左、袖口云纹右
├── 罩裙前片、罩裙后片、褶裥片×8（前 4 后 4）、裙摆金边（前/后）
├── 肩甲左、肩甲右（各含主盖 + 顶片）
├── 战靴左、战靴右（各含筒靴 + 靴口金环 + 楔形鞋头 + 金色鞋头盖）
├── 玉佩、玉佩绳、发簪、簪头珠
└── 云纹贴片×6（主袍下摆 2、罩裙前片 2、袖口 2）
L2 中组件（小组件组装，检查接缝与比例）
├── 上身组件 = 内层贴身袍 + 主袍 + 立领 + 领口金边 + 前襟
├── 袖组件左 = 宽袖左 + 袖口金边左 + 袖口云纹左（右同理）
├── 腰组件 = 腰封 + 金扣
├── 裙组件 = 罩裙前/后片 + 褶裥片×8 + 裙摆金边 + 罩裙云纹×2 + 主袍云纹×2
├── 配饰组件 = 肩甲左/右 + 玉佩 + 玉佩绳 + 发簪 + 簪头珠
└── 足组件 = 战靴左/右 + 鞋头左/右
L3 大组件（整套服装）
└── 上身 + 袖×2 + 腰 + 裙 + 配饰 + 足，穿到人体底座上试穿，
    检查层间隙（≥0.005 米）与关节穿帮（臂/腿活动处不穿帮）
```

## 各级检查（v2，脚本实测，待填）

- **L1 检查**：每个小组件单独看廓形比例——袍长、袖长、裙摆张开度、肩甲弧度、
  靴高，面数记在下表；比例失调只返工该组件。
- **L2 检查**：接缝处径向间隙 ≥0.005 米（主袍/内层、腰封/主袍、袖口/宽袖、
  裙片/主袍、玉佩/裙片、靴筒/腿），脚本逐项打印 PASS/FAIL。
- **L3 检查**：整套穿到底座上，层间隙与关节活动余量（臂/腿）逐项打印 PASS/FAIL。

## 灵感来源

- **地区与文化**：璃月（原神）——中国戏曲与传统服饰元素。立领、盘扣、宽袖、罩裙，
  戏曲行头「靠」与文官长袍的结合：上身挺括、下摆飘逸，站着像一幅画。
- **服装讲故事**：穿这套衣服的人是璃月的巡夜武官——白天在总务司当值（挺括立领、
  腰封、肩甲），夜里巡街（开衩裙摆方便行走，朱红罩裙在灯下显眼）。
- **防穿帮设计**：借鉴云堇的 overskirt 思路——外层罩裙只做前、后两片，
  两侧留开衩，衩口下露出中层长袍而不是皮肤，从根本上避免关节活动处穿帮。
- **层叠**：内层贴身袍 → 中层主袍 → 外层罩裙 → 肩甲与配饰，四层，每层之间留 0.005 米以上间隙。

## 廓形（v2）

- **上身**：立领（顶部微张）+ 收腰（腰封处最窄），肩线挺括（双层肩甲），A 字型向外展开；
  正面一条朱红前襟竖条 + 两颗盘扣
- **下身**：腰部收紧、下摆张开；罩裙为 **8 片褶裥**（前片 4、后片 4，每片为倒 V 形
  细条，脊高自腰向摆端放大到 0.032 米，颜色比裙片深一档，褶裥才看得见），主袍下摆
  在罩裙之下露出，裙摆金边 + 云纹
- **袖**：上臂贴身、中段微鼓、袖口喇叭形张开（灯笼袖廓形），袖口收金边 + 朱红云纹贴片
- **整体**：上紧下松、长短层次分明，站姿剪影呈「宝塔形」

## 云纹（v2，全部用几何体做，不靠贴图）

云纹母题 = **卷云环段**（300° 环形扇段，外径 0.045、内径 0.022 的金色扁平环段）
+ **中心圆点**（半径 0.012 金色圆片），共 6 处：

| 位置 | 数量 | 做法 |
|---|---|---|
| 主袍下摆正面（罩裙之下露出部分） | 2 | 金色贴片弯曲贴合袍面，中心 x=±0.075、z=0.40 |
| 褶裥罩裙前片 | 2 | 金色贴片，贴在两处褶裥脊线上（前片弧度 30% / 70% 处），z=0.70 |
| 袖口金边外侧 | 2 | 缩小版（外径 0.032），**朱红贴片**（金底上金纹看不见，改放朱红） |

- 贴片用 oriented_patch 生成：沿袍面法向偏移 0.007 米，沿曲面方向抛物线弯曲贴合，
  不得浮空、不得扎进袍面。

## v1 记录（2026-11-20，历史）

- v1 服装总面数：**526**（三角 148、四边 374、N-gon 4），15 个部件、四层穿搭。
- v1 发现并修复两个问题：①人体底座原为方形躯干，其扁平面在 |x|>0.17 处穿出椭圆长袍
  （胸前露出肤色条带）→ 底座躯干改椭圆筒；②底座赤脚与战靴鞋头同位置重叠造成
  z-fighting → 底座不再建赤脚，脚由战靴提供；③首版曝光过度（朱红发粉）→ 灯光能量 ×0.45、
  世界光强度 0.75。
- 法线自检：脚本建模时对全部网格做质心法向检查，翻转反向面；**扁平贴片/圆片不适用
  质心法向检查**（法向与质心方向垂直），贴片类一律靠构造时的绕序保证朝外，
  不得对其调用 fix_normals。
