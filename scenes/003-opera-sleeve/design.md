# 003 戏曲水袖礼服 · Opera Water-Sleeve Gown

中国戏曲旦角水袖礼服：红蓝戏曲配色 + 水袖 + 盘扣 + 头饰。
003 号作品，按 001 v2 确立的组件化流程（L1 → L2 → L3）从零制作。

## 角色故事

戏曲舞台上的旦角——一袭红袍登台，水袖一甩、身段一转，讲的是
“行头即人物”：水袖是手臂的延伸，盘扣是手工的体面，雉尾翎是
身份的标志。衣服首先是戏：每一处装饰在台上都有动作可做，
不为装饰而装饰。

## 线路与融合变量

- 线路：原创融合——以戏曲行头为本（不属于 DESIGN.md 四线路任何
  一条的直接复刻），廓形取戏曲长袍，配色取红蓝金戏曲三色。
- 融合变量只改一个：廓形保持戏曲长袍不变，配色用红蓝金
  （不用原神层叠、不用 techwear 绑带、不用异环都市剪裁）。

## 组件树（L1 → L2 → L3）

```
L1 小组件（每个单独建模、单独检查廓形比例）
├── 内层素衣（米白长袍，贴身打底）
├── 主袍（正红长袍，上身合体、裙摆外张，拖至脚面）
├── 斜襟（深蓝斜襟带两条，胸前交叉）
├── 盘扣×3（金色盘扣结，沿斜襟排布，几何小球+绳环）
├── 云纹贴片×3（金色几何云纹，胸前 1 处 + 裙前 2 处）
├── 水袖左/右（米白长袖，袖口外张成喇叭状，垂过手腕）
├── 袖口蓝边（深蓝袖口箍，收住水袖根部）
├── 腰封（深蓝宽腰封 + 金色腰带扣 + 前结蝴蝶结 + 垂带×2）
├── 裙摆褶裥×8（竖向凸条，绕裙一周，几何呈现）
├── 金色裙边（裙摆底边一圈金色镶边）
├── 绣鞋左/右（正红鞋面 + 金色鞋头，楔形鞋身）
├── 头饰（金色额箍 + 雉尾翎×2 + 耳侧金珠 + 红色流苏×2）
└── 五官（双眼 + 红唇，旦角妆面最简表达）
L2 中组件（小组件组装，检查接缝与比例）
├── 上身 = 内层素衣 + 主袍 + 斜襟 + 盘扣×3 + 云纹贴片
├── 袖 = 水袖左/右 + 袖口蓝边
├── 腰 = 腰封 + 腰带扣 + 蝴蝶结 + 垂带×2
├── 裙 = 主袍裙摆 + 裙摆褶裥×8 + 金色裙边
├── 足 = 绣鞋左/右
└── 首 = 头饰 + 五官

└── 上身 + 袖 + 腰 + 裙 + 足 + 首，检查层间隙（≥0.005 米）
    与关节穿帮（肩/肘活动处不穿帮，水袖不穿手）
```

## 廓形

- **上身**：合体长袍，肩线圆顺，斜襟自右肩斜至左腰，盘扣三枚
  沿斜襟排布；胸前金色云纹一处，点明戏曲纹样。
- **下身**：裙摆自腰部外张、拖至脚面，八道竖褶裥绕裙一周，
  金色裙边收底；绣鞋尖只露鞋头一点。
- **水袖**：袖长过手，袖口外张成喇叭状，米白袖身在红袍两侧
  垂成两条柔和的竖线，是全套最醒目的剪影。
- **整体剪影**：上身挺拔、下身舒展，水袖 + 雉尾翎拉出纵向线条；
  人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

| 角色 | 颜色 | sRGB hex | linear RGB（脚本用） | 粗糙度 / 金属度 | 用处 |
|---|---|---|---|---|---|
| 主色 1 | 戏曲红 | #C1272D | (0.533, 0.020, 0.026) | 0.75 / 0.0 | 主袍、绣鞋、流苏 |
| 主色 2 | 黛蓝 | #1B3A6B | (0.011, 0.042, 0.147) | 0.75 / 0.0 | 斜襟、袖口、腰封 |
| 主色 3 | 米白 | #F5EFE0 | (0.913, 0.863, 0.745) | 0.85 / 0.0 | 内层素衣、水袖 |
| 点缀 | 鎏金 | #D4A017 | (0.658, 0.352, 0.009) | 0.35 / 0.6 | 盘扣、云纹、裙边、头饰、鞋头 |
| 肤色 | — | #D9A67E | (0.694, 0.381, 0.209) | 0.7 / 0.0 | 人偶头、手（沿用 001 v2 的肤色） |
| 发色 | 乌黑 | #17181A | (0.009, 0.009, 0.010) | 0.85 / 0.0 | 发髻（头饰下露出的发） |
| 眼睛 | — | #0A0A0A | (0.003, 0.003, 0.003) | 0.6 / 0.0 | 人偶最简五官 |
| 红唇 | — | #C1272D | (0.533, 0.020, 0.026) | 0.6 / 0.0 | 旦角妆面红唇 |

- 配色逻辑：红蓝两档主色靠色相对比拉开层次（不是靠明度），
  米白水袖是全套最亮的色块，鎏金只占约 5%，是“行头点睛色”。
- **红色发暗的防线**：红袍粗糙度 0.75（缎面微光）、水袖 0.85
  （棉麻哑光）、鎏金金属度 0.6 提亮；层间隙 ≥0.005 米保证阴影缝；
  轮廓光不能省。

## 纹理（全部用几何体，不靠贴图——001 v2 的标准）

| 纹理 | 做法 |
|---|---|
| 云纹贴片 | 每处 3 个重叠金色圆片拼成云头形，贴在袍面，高出表面 0.004 米 |
| 盘扣 | 金色小球 + 绳环（小圆环），沿斜襟排 3 枚 |
| 裙摆褶裥 | 8 条竖向凸条绕裙一周，每条高出裙面 0.006 米、宽 0.028 米，\n  用深一档的同色红（#9E1B22 → linear (0.340, 0.011, 0.016)）做褶裥，\n  以色差读出立体感（v1 同色 0.004 浮雕在渲染里完全看不见，已改） |
| 金色裙边 | 裙摆底边一圈金色环带 |
| 雉尾翎 | 两根长翎（渐细圆管），自头顶向后上方斜伸，翎尖金色小球 |
| 流苏 | 耳侧红色细圆柱垂穗，末端金色小球 |

## 沿用 001 v2 / 002 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；底座不建赤脚，脚由绣鞋提供。
- 人偶最简五官：两只眼睛 + 红唇，3/4 正面一眼认出正面。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片/圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
- 雉尾翎伸出头顶约 0.25 米，取景时把顶部取到 2.0 米再测占比。
