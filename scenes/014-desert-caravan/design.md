# 014 沙漠商队旅人套装 · Desert Caravan Traveller Set

整套服装：沙漠商队的旅人——沙色长袍 + 陶土罩裙 + 头巾 + 斜挎行囊。
014 号作品，按 001 v2 确立的组件化流程（L1 → L2 → L3）从零制作。
BACKLOG 最上面未勾项；地区衣橱新方向：沙漠。

## 角色故事

她跟着商队走过三片沙漠：头巾是防风沙的，行囊里装着水、干粮和
一张画了一半的地图；袍子上的太阳纹是商队出发那天早上画上去的，
走到哪里，太阳就跟到哪里。陶土色的罩裙沾过三次沙暴的土，洗不掉了，
她说那是路的记号。

## 线路与融合变量

- 线路：原神式层叠幻想（DESIGN.md：服装讲故事、元素配色、
  层叠与配饰、文化融合）——沙漠是“新地区衣橱”，先定地区再定元素
  （须弥沙漠风：沙色 + 陶土 + 绿松石点缀）。
- 融合变量只改一个：**配色走沙漠暖调**（沙色 + 陶土 + 深棕），
  廓形保持原神式层叠长袍（立领→翻领、长袍、罩裙、配饰），
  不用机能风的黑白打底与绑带；绿松石只做点缀（头巾带、太阳纹、
  行囊扣），不抢暖主调。

## 廓形

- **主袍 + 罩裙**：沙色主袍从肩到摆微张（0.300→0.460），
  陶土罩裙从腰到摆大张（0.340→0.490），下半身陶土、上半身沙色，
  远看就是“沙丘上的晚霞”。
- **头巾**：沙色包头环裹住发顶，绿松石巾带压住环口，额前一颗
  绿松石宝石是商队的标记；右侧一条垂巾垂到胸口，是全套最飘的一笔
  （垂巾放相机侧右前方，后背垂巾看不见，008 圆盾的教训）。
- **行囊**：绳带从左肩斜挎到右腰，行囊包挂在右腰前侧（相机侧），
  包盖 + 绿松石扣 + 垂穗，旅人的身份件必须立在画面里。
- **整体剪影**：长袍拖地只露靴尖，人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

## 沿用 001 v2 / 002 / 003 / 004 / 005 / 007 / 008 / 009 / 011 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；人偶最简五官：两只眼睛。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片/圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
- 挂件要放在看得见的位置（008 膝盘被裙摆挡住的教训：
  太阳纹放在主袍胸口与罩裙正面，行囊挂在相机侧右腰，不藏在层下；
  头巾垂巾放右前方，后背垂巾看不见不做）。
- 同色浮雕看不见（003 的教训）：太阳纹用绿松石压在沙色袍上、
  小太阳用沙色压在陶土裙上、褶裥用深棕压在陶土裙上，靠色差读出层次。
- 底座不建赤脚（008 的教训）：009 的腿管到地面 + 楔形脚掌，
  沙靴盖住小腿与脚掌，脚不悬空。
- 相机侧配饰才看得见（008 圆盾的教训）：行囊在右腰（相机侧），
  不被身体挡住。
- **013 质检的教训（本轮已修）**：011 的靴底悬空 0.02 米——楔形靴掌
  中心 z=0.02 导致底面 z=0.02；本轮靴掌与人偶脚掌中心一律 z=0.0，
  底面 z=0.0 落地，L3 加“靴底落地 z=0.000”检查。
- **013 质检的教训（本轮已修）**：011 腰带下沿 6 个顶点落在罩裙锥面内
  （z=0.70 两侧，罩裙比腰带宽）；本轮腰封改上窄下张（0.345→0.380），
  下沿比同高罩裙宽 0.012，L2/L3 加腰封下沿间隙检查。

## 返工记录（v1 → v2，轮次内）

- 靴掌顶面改高：v1 靴掌楔形顶面 0.09/0.03，低于人偶脚掌顶面
  0.10/0.045，肤色脚掌从靴面戳出来；改靴掌顶面 0.11/0.05（与 011
  相同），盖住人偶脚掌，靴面全深棕，落地 z=0.0 不变。
- 头巾加包头顶盖：v1 只有包头环，深棕发顶从环上露出来像顶小黑帽；
  v2 加沙色扁球顶盖（r=0.24，纵向压扁 0.55），盖住发顶，头巾读成
  完整包头；绳结移到顶盖右后上方（0.22, 0.12, 1.68），半嵌在盖面上。
