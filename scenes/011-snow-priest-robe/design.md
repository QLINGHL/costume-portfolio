# 011 雪国祭司长袍 · Snow Kingdom Priest Robe

整套服装：雪国祭司的礼服长袍——雪白主袍 + 冰蓝罩裙 + 白毛领 +
祭司金冠 + 手持冰晶长杖。011 号作品，按 001 v2 确立的组件化流程
（L1 → L2 → L3）从零制作。

## 角色故事

雪国的祭司站在风雪里给人占卜天气：白袍是雪，蓝裙是冰湖，
毛领是驯鹿的绒，胸口的雪花是她第一次占卜成功那天落下的形状，
金冠上的五根冰晶是五个冬天的记号。长杖不是武器，是量雪的尺子——
杖顶的冰晶朝哪边亮，哪边就要下雪了。

## 线路与融合变量

- 线路：原神式层叠幻想（DESIGN.md：服装讲故事、元素配色、
  层叠与配饰、文化融合）——雪国是“北方地区衣橱”，先定地区再定元素。
- 融合变量只改一个：**配色走雪国白蓝**（雪白 + 冰蓝 + 深蓝），
  廓形保持原神式层叠长袍（立领→毛领、长袍、罩裙、配饰），
  不用机能风的黑白打底与绑带；金色只做点缀（冠、扣、杖环），
  不抢白蓝主调。

## 组件树（L1 → L2 → L3）

```

├── 腰 = 腰封 + 金扣（检查腰封与主袍间隙、金扣浮雕）
```

## 廓形

- **主袍 + 罩裙**：雪白主袍从肩到摆微张（0.300→0.460），
  冰蓝罩裙从腰到摆大张（0.330→0.480），下半身蓝、上半身白，
  远看就是“雪地上的冰湖”。
- **毛领**：白色毛领圈盖住肩线，前襟 3 团毛绒球垂到胸口，
  是全套最暖的一笔。
- **雪花纹**：胸口一朵大雪花（直径 0.20 米）是视觉中心，
  裙摆三朵小雪花排成弧线，上下呼应。
- **长杖**：右手持杖，杖身从地面直通头顶上方（z 0.05→1.45），
  晶顶高出冠顶，是全套最高的点，3/4 正面看杖在身体右侧，
  不挡脸、不挡雪花。
- **整体剪影**：长袍拖地只露靴尖，人物 3/4 正面，占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

- 配色逻辑：雪白主袍占约 55%、冰蓝罩裙与雪花占约 30%、
  深蓝腰封与褶裥占约 10%、金色点缀约 5%（冠、扣、杖环）；
  毛领纯白比主袍更亮一档，领口一眼就亮起来。
- **长杖挂件的取舍**：BACKLOG 写的是“长杖挂件”，但腰挂小杖会被
  罩裙挡住看不见（008 膝盘被裙摆挡住的教训），所以改成右手持的
  整根长杖——杖是祭司的身份件，必须立在画面里；腰上不再另挂小杖，
  避免一件东西做两遍。

## 纹理（全部用几何体，不靠贴图——001 v2 的标准）

| 纹理 | 做法 |
|---|---|
| 胸前雪花 | 冰蓝圆盘（12 边，r=0.04）+ 6 条冰蓝臂（薄盒，长 0.09、宽 0.018），高出主袍面 0.008 米 |
| 裙摆雪花 | 冰蓝圆盘（8 边，r=0.03）+ 3 条交叉臂（薄盒），高出罩裙面 0.008 米 |
| 褶裥 | 8 条深蓝竖条贴罩裙面，0.006 浮雕，随裙摆张度走（008 pteruges 的做法） |
| 毛领 | 白色毛领圈（椭圆管，上下两环）+ 前襟 3 团毛绒球（小球 r=0.045） |
| 冠晶刺 | 5 根冰蓝晶刺（薄盒，竖立在金环上）+ 中央高刺 |
| 杖环 / 晶顶 | 杖身 3 道金环（细管）+ 冰蓝晶顶（拉长球体，纵横比 1:1.6） |

## 沿用 001 v2 / 002 / 003 / 004 / 005 / 007 / 008 / 009 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；人偶最简五官：两只眼睛。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片/圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。
- 挂件要放在看得见的位置（008 膝盘被裙摆挡住的教训：
  雪花纹放在主袍胸口与罩裙正面，不藏在层下；长杖改右手持）。
- 同色浮雕看不见（003 的教训）：雪花用冰蓝压在雪白袍上、
  褶裥用深蓝压在冰蓝裙上，靠色差读出层次，不靠 0.006 浮雕。
- 底座不建赤脚（008 的教训）：009 的腿管到地面 + 楔形脚掌，
  白靴盖住小腿与脚掌，脚不悬空。
- 相机侧配饰才看得见（008 圆盾的教训）：长杖在右手（相机侧），
  晶顶高出冠顶，不被身体挡住。

## 返工记录（v1 → v3，轮次内）

- 冠刺取消 Z 轴旋转：v1 晶刺按 (ang-90) 绕 Z 旋转，200°/340° 两根
  几乎横过来，像蓝棍子从脑袋两侧戳出来；改全部竖直，只按金环
  位置落点，冠才像冠。
- 裙摆雪花冰蓝 → 雪白：v1 冰蓝雪花压在冰蓝罩裙上，同色浮雕看不见
  （003 的教训）；改雪白后三朵小雪花在蓝裙上排成弧线，上下呼应
  胸前大雪花。
- 宽袖起点 0.05 → 0.0 + 加肩垫：v1 袖口与毛领之间露一小块手臂肤色；
  v2 袖子从肩点起做仍能从袖口俯视看到人偶手臂顶盖（袖筒无盖、
  相机俯角看得进筒口）；v3 在肩点加白肩垫球堵住筒口，肤色补丁消失，
  肩垫顺带读成肩部造型。
- 毛领 2 环 → 3 环：v1 毛领只有 0.08 高、像一块白板压在肩上；
  v3 上窄下张（0.320→0.360），0.12 高，有了领口的厚度。
