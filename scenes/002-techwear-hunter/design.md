# 002 机能风猎手套装 · Techwear Hunter Set

鸣潮式机能风 techwear（DESIGN.md 线路二），荒野猎手 / 巡林斥候。
002 号作品，第一件完全按 001 v2 确立的组件化流程（L1 → L2 → L3）从零做的衣服。

设计预备稿：`~/workspace/goals/goal-2/files/002-techwear-hunter-design-prep.md`

## 角色故事

鸣潮式世界的荒野猎手 / 巡林斥候——白天追踪、夜里潜行。
衣服首先是工具：兜帽防雨、高领护颈、胸前挂袋装弹药 / 采集物、
战术腰带挂刀鞘、膝盖加固、靴底防滑。讲得出每件东西的用途，
不为装饰而装饰。

## 线路与融合变量

- 线路：鸣潮式机能风 techwear，不混原神层叠、不混异环都市。
- 融合变量只改一个：廓形保持 techwear 修身，配色用猎手的琥珀橙做功能点缀。
- Techwear 逻辑（2026-11-20 核过，fuga-studios 2026 指南）：功能先行、
  廓形第二、颜色最后；90% 哑光黑灰 + 一个功能色；每处五金（扣、拉链、
  绳扣）都要有可见用途；2026 年趋势是绑带减少、少“商场忍者”感——
  所以绑带只留 3 处有功能的（胸带、腰带、靴口），其余用拉链、口袋、
  织带条纹来表现机能感，不要满身绑带。

## 组件树（L1 → L2 → L3）

```
L1 小组件（每个单独建模、单独检查廓形比例）
├── 内层速干衣、主夹克、夹克下摆束绳
├── 高领、领口拉链（拉链齿用几何小方块排布）、兜帽（兜帽+帽檐+帽绳扣×2）
├── 前襟拉链、胸前口袋×2（左胸扁袋+右胸立体袋，袋盖+按扣）
├── 斜挎胸带（胸前对角织带 + 方扣 1 个，挂一个小工具袋）
├── 战术腰带（腰带 + 方扣 + 腰带织带环×4）
├── 战术背心片（前胸织带条纹×3，几何凸条，不是贴图）
├── 护臂左/右（前臂硬壳片 + 绑带扣各 1）
├── 工装裤（腰至踝，收口）、大腿口袋×2（翻盖+按扣）、膝盖加固片×2
├── 长靴左/右（靴筒 + 靴口束带扣 + 厚底 + 靴底防滑纹条）
├── 手套左/右（简化的手套筒，指节不做，免得面数爆炸）
├── 肩灯（小圆筒+透镜片，琥珀橙光面——全套唯一的发光点）
└── 通讯耳机（猎手通讯耳机，挂在颈侧，小圆环+短杆）
L2 中组件（小组件组装，检查接缝与比例）
├── 上身 = 内层速干衣 + 主夹克 + 高领 + 拉链 + 兜帽 + 胸前口袋×2
├── 胸挂 = 斜挎胸带 + 工具袋 + 战术背心片（织带条纹）
├── 腰 = 战术腰带 + 方扣 + 织带环×4
├── 腿 = 工装裤 + 大腿口袋×2 + 膝盖加固片×2
├── 臂 = 护臂左/右 + 手套左/右
└── 足 = 长靴左/右 + 靴底防滑纹
L3 大组件（整套穿到底座上试穿）
└── 上身 + 胸挂 + 腰 + 腿 + 臂 + 足 + 肩灯 + 通讯耳机，
    检查层间隙（≥0.005 米）与关节穿帮（肩/肘/膝活动处不穿帮）
```

## 廓形

- **上身**：修身夹克，肩线平直，高领拉到下巴，兜帽收在领后（帽子不戴在头上、
  搭在颈后，免得遮住五官）；胸前斜挎带一条对角线，打破全黑的横平竖直。
- **下身**：上宽下收的工装裤，大腿口袋立体凸出，膝盖加固片微鼓，裤脚收进靴筒。
- **整体剪影**：上身挺括、下身利落，站姿呈倒三角 + 直筒腿；人物 3/4 正面，
  占画面约 70%。

## 配色（主色 3 个 + 点缀 1 个）——写死色值，sRGB hex → linear 已换算

脚本只用 linear 值，不许凭感觉填（001 v1 洗淡的根因就是把 sRGB 当 linear 用）。
换算公式：sRGB ≤ 0.04045 时 linear = sRGB / 12.92；否则
linear = ((sRGB + 0.055) / 1.055) ^ 2.4。

| 角色 | 颜色 | sRGB hex | linear RGB（脚本用） | 粗糙度 / 金属度 | 用处 |
|---|---|---|---|---|---|
| 主色 1 | 哑光黑 | #17181A | (0.009, 0.009, 0.010) | 0.9 / 0.0 | 主夹克、工装裤、兜帽 |
| 主色 2 | 炭灰 | #3A3F44 | (0.042, 0.050, 0.058) | 0.6 / 0.0 | 内层速干衣、护臂、靴筒 |
| 主色 3 | 深灰蓝 | #23282E | (0.017, 0.021, 0.027) | 0.8 / 0.0 | 战术背心片、膝盖加固片、口袋袋盖 |
| 点缀 | 琥珀橙 | #E85D04 | (0.807, 0.109, 0.001) | 0.4 / 0.0 | 肩灯透镜、拉链拉头、胸带方扣边、靴口绳扣——只用在小面积功能点上 |
| 五金 | 枪灰金属 | #7A7F85 | (0.195, 0.212, 0.235) | 0.3 / 0.8 | 方扣、按扣、织带环、拉链齿 |
| 肤色 | — | #D9A67E | (0.694, 0.381, 0.209) | 0.7 / 0.0 | 人偶头、手（沿用 001 v2 的肤色） |
| 发色 | 深灰 | #2A2D33 | (0.023, 0.026, 0.033) | 0.85 / 0.0 | 短发（猎手短发，不做长发/发髻） |
| 眼睛 | — | #0A0A0A | (0.003, 0.003, 0.003) | 0.6 / 0.0 | 人偶最简五官 |

- 配色逻辑：黑灰三档靠明度拉开层次（不是靠颜色），琥珀橙只占约 5%，
  是“功能可见色”（夜间定位、拉头易找），不是装饰色。
- **黑色一团糊的防线**：三档黑灰必须在渲染里分得开——夹克哑光（粗糙度 0.9）、
  护臂 / 靴筒半哑光（0.6）、五金金属（0.3 + 金属度 0.8）；层间隙 ≥0.005 米
  保证阴影缝；轮廓光不能省。背景比 001 稍亮（中灰渐变），免得黑衣糊进背景。

## 纹理（全部用几何体，不靠贴图——001 v2 的标准）

| 纹理 | 做法 |
|---|---|
| 织带条纹（背心片） | 3 条横向凸条弧带，贴合背心片曲面，高出表面 0.006 米，弧度 (245°, 295°) |
| 拉链齿 | 沿拉链线排小方块（每颗约 0.008 米），拉头一个稍大的楔形块，琥珀橙 |
| 口袋立体感 | 右胸袋与大腿袋做成凸出盒体（不是平面贴片），袋盖翻折角 |
| 靴底防滑纹 | 靴底两侧加 4 条横向防滑纹条 |
| 膝盖加固片 | 压扁椭球凸片，高出裤面约 0.02 米 |
| 绳扣 | 小圆柱 + 穿绳孔（圆环），琥珀橙，帽绳与靴口各 1 对 |
| 斜挎胸带 | 5 段小盒沿胸面曲面拼成对角线，贴合身体弧度，不悬空 |

## 面数目标（整套 ≤1500，目标约 1000）

夹克约 200（含兜帽 60、口袋 80）、裤约 180（含口袋 60、膝盖片 40）、
靴约 140、护臂 + 手套约 120、腰带 + 胸带 + 背心片约 150、五金小件约 120、
肩灯 + 耳机约 40、内层约 40。合计约 990。

## 各级检查（脚本实测，待填）

- **L1 检查**：每个小组件单独看廓形比例——夹克长、裤长、靴高、兜帽大小，
  面数记在脚本输出；比例失调只返工该组件。
- **L2 检查**：接缝处径向间隙 ≥0.005 米（夹克 / 内层、腰带 / 夹克、
  护臂 / 手臂、靴筒 / 腿、口袋 / 夹克、膝盖片 / 裤），脚本逐项打印 PASS/FAIL。
- **L3 检查**：整套穿到底座上，层间隙与关节活动余量（臂 / 腿）逐项打印 PASS/FAIL。

## 沿用 001 v2 已验证的东西（不要重踩坑）

- 人体底座椭圆筒躯干（方形会穿出衣服）；底座不建赤脚，脚由长靴提供。
- 人偶最简五官：两只眼睛 + 短发，3/4 正面一眼认出正面。
- 灯光能量 ×0.45、世界光 0.75（001 v1 曝光过度的教训）。
- 扁平贴片 / 圆片不适用质心法向检查，靠构造绕序保证朝外。
- 渲染前调 setup_render 再投影测人物占比（001 v2 的 FRAME_FRACTION 教训）；
  3/4 正面、人物约占画面 70%、Eevee 1024×1024、效果图 + 线框图各一张。

- [ ] 一眼看出是机能风猎手，不是黑衣路人：高领 + 兜帽 + 斜挎带 + 大腿口袋 + 长靴全可见
