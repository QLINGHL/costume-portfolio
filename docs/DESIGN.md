# 服装设计指南

本仓库每件作品先定设计、再建模型。设计语言主要参考两条线，外加原创融合。

## 线路一：原神式层叠幻想（Genshin Impact）

研究要点（2026-11-20 查证）：

- **服装讲故事**：服装反映角色的出身、职业与旅程（如琴的骑士团蓝白配色 + 高领 + 皮靴对应蒙德风；钟离的深色正装对应往生堂工作）。
- **元素配色**：配色与角色挂钩（如凝光金黄 + 黑白、菲谢尔紫黑 + 雷元素），主色不超过 3 个 + 1 个点缀色。
- **层叠与配饰**：披风、刺绣、系带、分层布料、角色专属挂件（如行秋外套内侧的水纹暗纹呼应水元素）。
- **文化融合**：不同地区对应不同现实文化（蒙德欧式骑士、璃月中国戏曲、稻妻日式、枫丹法式），先定地区再定元素。
- **防穿帮**：云堇的设计过程特意选了 overskirt（罩裙）造型来避免模型穿插；关节活动处的裙摆、袖口要留活动余量。

## 线路二：鸣潮式机能风（Wuthering Waves / techwear）

研究要点（2026-11-20 查证）：

- **techwear 核心**：修身合体、碳纤维质感、哑光面料，功能与时髦并存。
- **黑白打底 + 亮色点缀**：全员黑白打底，再用一个亮色区分角色。
- **绑带与扣具**：腰带、绑带、战术背带是统一的视觉语言（如漂泊者、秧秧裙上的绑带）。
- **地区衣橱**：每个地区有自己的衣橱（今州飘逸长袍、黎那汐塔嘉年华与角斗士铠甲、拉亥罗伊机甲驾驶服），先定地区再定剪裁。
- **服装即护照**：不用开口就能从服装读出角色来自哪里、做什么。

## 线路三：异环式都市时装（Ananta）

研究要点（2026-11-20 查证：17173 时装新闻、TapTap 玩家评价、交易猫时装汇总）：

- **现代都市日常服**：异环是超自然都市开放世界（完美世界 Hotta Studio），衣服首先是
  「这个人每天穿的衣服」——西装、学院风、居家服、运动风、街头潮服，不是礼服也不是战袍。
- **职业一眼可辨**：角色设计往刻板印象上做，一眼能知道角色的属性与职业
  （达芙蒂尔：干练西装 + 短发高冷 + 蓝色挑染；娜娜莉「学园之星」：黑白学院风 +
  风纪委员袖标，袖标由角色亲手制作）。
- **现实配色**：黑白灰、藏青打底 + 一个亮色点缀（橙色系造型、蓝色挑染），
  不追求大面积高饱和；主角时装库有藏青居家常服、橙色造型、夏日泳装、纯白狱服（剧情定制）。
- **版型合体修身**：贴合身体线条，少层叠、少拖摆，方便都市行动（开车、跑动、探索）；
  同一角色多套风格成矩阵（学院 / 居家 / 运动 / 街头），设计时成套想。
- **非人元素点缀**：兽耳、尾巴、异色挑染等小面积非人特征，作为角色辨识点
  （异环特化了非人成分）；曳尔沐的三套时装横跨蓝色长裙、白色毛衣、赛博朋克街头潮服，
  风格跨度大是这条线的特点。

## 原创融合

两条线可以混搭，但要讲得出逻辑，例如：

- 赛博汉服：汉服廓形（交领、宽袖）+ 机能面料与发光纹路
- 戏曲机能风：戏曲配色与水袖 + 战术绑带与扣具
- 每次融合只改一个变量（廓形、面料、配色三选一），其余保持原线路，避免四不像。

## 组件化制作流程（2026-11-20 确立，001 v2 起每件都按这个做）

照原神 / 鸣潮 / 异环做衣服的路子：一个小组件合成一个大组件，一步一步组装，
不许整件一次成型。

```
L1 小组件：每个单独建模、单独检查廓形比例
  （立领、领口金边、前襟、腰封、金扣、宽袖、袖口金边、罩裙片、褶裥片、
   裙摆金边、肩甲、战靴、鞋头、玉佩、发簪……）
  ↓ 每件看廓形比例，比例失调只返工该组件
L2 中组件：小组件组装，检查接缝与比例
  （上身 = 立领+领口金边+前襟+主袍；袖 = 宽袖+袖口金边；腰 = 腰封+金扣；
   裙 = 罩裙片+褶裥+裙摆金边；配饰 = 肩甲+玉佩+发簪；足 = 战靴+鞋头）
  ↓ 接缝处径向间隙 ≥0.005 米，逐项打印 PASS/FAIL
L3 大组件：整套服装穿到人体底座上试穿
  （上身+袖+腰+裙+配饰+足，检查层间隙 ≥0.005 米与关节穿帮）
  ↓ 哪级不过只返工那级，不要整件推倒
```

- 脚本结构：`build_001.py` 按组件分函数，每个组件一个 `build_*()` 函数，
  输出各组件面数，最后组装；`design.md` 里写清组件树与每级检查结果。
- 人偶底座、配色方案这类已验证可用的部分可以保留复用，不必每件重做。

## 建模标准

- **人体底座**：每套服装建在统一的中性人体底座上（约 1.7 米，与 blender-portfolio 的 002 角色同比例），
  服装与底座分开成件，方便换装与质检。
- **分层顺序**：内层（贴身）→ 中层（主服装）→ 外层（披风 / 罩裙 / 肩甲）→ 配饰；层与层之间留 0.005 米以上间隙防穿帮。
- **面数目标**：整套服装控制在 1500 面以内，单件配饰 300 面以内；N-gon 尽量为 0。
- **配色**：先定色板写进设计说明，建模时按色板取色，不临场发挥。
- **设计说明**：每件作品配一个 .md，写清灵感来源、廓形、配色、部件清单、面数。
- **v2 标准（2026-11-20，001 v2 确立）**：纹样必须用几何体呈现（贴片/环段/浮雕，
  不靠贴图或纯色）；裙摆褶裥要做成看得见的立体褶（独立褶裥片或明显起伏，
  不是平滑裙面）；配色用深饱和色（色值先按 sRGB hex → linear 换算写死进设计说明，
  不许凭感觉填）；人偶要有最简五官（至少两只眼睛），正面一眼能认出是正面；
  构图用 3/4 正面、人物占画面约 70%。

## 渲染与质检标准

- Eevee 1024×1024，三点式影棚光，平面着色；正面效果图 + 线框图各一张。
- 目视检查：服装完整、构图居中、无全黑、无穿帮、无漂浮部件。
- 质检类作品的数值必须用脚本实测填写，不编造；训练数据类标注必须用相机投影真实算出。
- v2 渲染标准：3/4 正面视角、人物占画面约 70%、柔和地面阴影、轮廓光、
  中性渐变背景（顶部浅灰 → 底部深灰，地面颜色贴近背景底部、弱化地平线）；
  目视标准是「一眼看出是件精致的服装而不是方块拼的」——纹样、褶裥、饱和配色缺一不可。
